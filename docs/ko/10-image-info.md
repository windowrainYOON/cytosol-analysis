# 이미지 정보 탭

[← 설명서 목차](README.md) · [English](../en/10-image-info.md)

현재 이미지 파일에 기록된 획득 설정을 표 두 개로 보여 줍니다. 실험 조건을
확인하거나 Methods를 쓸 때 씁니다.

## 채널별 획득 설정

채널마다 한 열, 파일에 기록된 만큼:

- 형광체와 여기/방출 파장,
- 레이저 파장과 레이저 세기(소프트웨어에 저장된 설정값, %),
- 레이저 라인의 정격 최대 출력과 명목 출력(최대 × 설정값),
- 노출 시간, 또는 pixel dwell / 프레임 시간 / averaging,
- 검출기, 검출기 전압(gain), digital gain, offset, 검출 파장 범위,
- pinhole(µm, AU).

레이저 세기는 소프트웨어 설정값입니다. 명목 출력은 광섬유 입력 기준이며, 시료
면에서의 실제 파워는 어느 파일에도 기록되지 않습니다.

## 이미지 · 장비 · Bleaching

- 이미지 크기, 픽셀 크기와 시야, Z 간격, 슬라이스 수, 프레임 간격과 총 시간.
- 대물렌즈(이름, NA, 침지액), 현미경, 획득 소프트웨어.
- bleaching이 있는 CZI(FRAP): bleach 레이저와 세기, 반복 횟수, 시간, bleach
  횟수, 각 bleach 뒤 프레임, bleach 전 프레임, bleach ROI마다 위치와 크기(ROI
  자체는 [마커 탭](05-markers.md)에서 그림).
- 자극(stimulation)이 있는 OIR(FRAP): 자극 레이저와 세기, 반복 횟수, bleach 전 프레임,
  자극 영역. [FRAP 측정 탭](14-frap.md)이 이 bleach 영역과 프레임을 씁니다.

## 형식별 내용

| 형식 | 내용 |
|---|---|
| CZI | 전부 읽음 |
| OIR | 레이저 %, PMT HV / offset / gain, pinhole, 염료, 스캔 속도 |
| TCF | FL Ex/Em, 광원 세기 %, 노출 |
| TIFF | ImageJ / OME 메타데이터에 있는 만큼 |

## 복사와 저장

- **표 복사**(탭 안의 버튼): 두 표를 탭으로 구분된 글로 복사(엑셀에 붙여넣기).
- **이미지 정보 › CSV 저장…**. **모든 분석 결과 통합
  저장**(`Ctrl+Shift+E`)도 이미지마다 `<이름>_info.csv`를 씁니다.
- **이미지 정보 › 원본 메타데이터 저장…**: 파일에 들어 있는 메타데이터 전체(CZI/OIR XML, TCF
  속성)를 그대로 저장합니다.
