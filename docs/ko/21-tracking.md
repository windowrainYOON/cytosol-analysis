# 입자 추적 탭 (v0.66, Z 투영 v0.69, ParticleTracker 방식 v0.70, 결과 폴더 v0.71, 신호 기준 v0.72)

시간축이 있는 이미지에서 입자 ROI 탭의 검출 설정을 모든 프레임에 적용하고, 프레임 사이 같은 입자를 이어
트랙을 만듭니다. ParticleTracker 앱의 연결 · 측정 방법을 그대로 옮겼습니다.

열기: Tool › **입자 추적** › 입자 추적 탭 열기 (또는 View 메뉴).

## 실행

- **추적 실행**: 현재 이미지를 추적합니다 (1 검출 카드의 프레임 범위).
- **모든 이미지에 실행**: 시간축이 있는 모든 이미지를 추적합니다. 파일 › 일괄 분석의 **입자 추적** 단계도
  같은 일을 합니다.

## 1 검출

- **입자 검출**: 입자 ROI 탭의 채널 · 검출 방식(자동 (유의성) / 점 모양 강조 / threshold)과 입자 기준을
  그대로 씁니다. 바꾸려면 입자 ROI 탭에서 바꿉니다.
- **방식** › **ParticleTracker와 같게 (형광 원본 해상도)** (Tomocube TCF에 RI와 형광이 함께 있을 때만 보임, 기본
  켜짐): ParticleTracker 앱의 코드(1.11, 바꾸지 않고 옮김)를 TCF 파일 자체에 그대로 실행합니다. 형광 원본
  해상도에서 reference 채널의 입자 검출(ParticleTracker 검출, k는 입자 ROI 탭이 ParticleTracker 방식일 때 그
  값, 아니면 10) → 프레임마다 형광 → RI 정합과 reference ↔ measure 정합 → RI 세포 분할 · 세포 흐름 · 퍼진
  세포막 · 분열 세포 → 패턴 예측 · 2단계 외형 연결 · gap closing → ROI 측정 · 합쳐짐 · 트랙 분류(분열 세포의 트랙은
  `excluded_mitotic`)까지 같은 순서입니다. 같은 파일에서 ParticleTracker와 검출 · 트랙 · 비율이 같습니다 (CSV
  반올림 차이만). reference = 입자 ROI 탭의 채널 (형광이 아니면 비율 A, 그다음 마지막 CH), measure = 비율 B.
  이때 세포 ROI 선택은 숨겨지고 (ParticleTracker는 늘 RI로 프레임마다 세포를 찾음), Z 투영이 꺼져 있으면 이 앱의
  방식으로 추적합니다. 끄면 아래 방식으로 화면의 영상(형광을 HT 격자에 맞춘 영상)에서 추적합니다.
- **세포 ROI**:
  - *지금 세포 ROI 그대로*: 세포질 ROI 탭의 ROI를 모든 프레임에 씁니다.
  - *프레임마다 검출 + ID 연결*: 세포질 ROI 탭의 설정으로 프레임마다 세포를 찾고, 앞 프레임과 30 % 이상
    겹치는 세포에 같은 번호를 줍니다 (세포가 움직이거나 모양이 바뀔 때). HT (RI) 영상은 핵 없이 RI만으로
    세포를 찾습니다.
  - *세포 ROI 없이*: 이미지 전체에서 찾습니다 (세포 안 / 밖 구분 없음).
  프레임마다 검출할 때 HT (RI) 세포는 ParticleTracker의 세포 분할 코드를 그대로 씁니다: 입자를 opening으로
  지운 세포 몸체 영상, 4 프레임마다 모은 표본의 triangle (세포 영역) / Otsu (세포 중심) threshold, watershed,
  앞 프레임과 30 % 넘게 겹치면 같은 번호, 세포 흐름도 세포 몸체 영상으로. 다른 세포는 세포질 ROI 탭의 설정으로
  찾되 프레임 가장자리 세포도 둡니다.
- **Z 스택** › **Z 투영 후 추적** (Z 스택이 있는 이미지에서만 보임, 기본 켜짐): 프레임마다 Z 스택을 2D로
  투영한 영상에서 입자를 찾고 잇습니다. 뷰어의 Z 슬라이더와는 따로입니다.
  - **최대 투영 (MIP)** (기본, ParticleTracker와 같음): Z마다 가장 밝은 값. 작은 입자가 잘 보입니다.
  - **평균 투영**: Z 평균. 잡음이 적고 밝기가 Z 전체를 대표하지만, 한 장에만 있는 흐린 입자는 약해집니다.
  - 끄면 뷰어의 Z 슬라이더에서 고른 한 장(또는 뷰어의 최대 투영)으로 추적합니다. 아래 안내 줄이 지금 어느
    Z로 추적하는지 알려 줍니다.
- **프레임**: 추적할 범위.

## 2 연결 (추적)

다음 프레임의 검출과 짝을 맞출 때(선형 할당), 비용은 예측 위치에서의 거리 + 밝기 차 + 크기 차 + 세포가
바뀐 벌점 + 주변 입자와 다르게 움직인 벌점입니다.

RI 채널이 있으면 (Tomocube TCF) ParticleTracker처럼 **두 번 연결**합니다: 1차 연결 중 확실한 연결(패턴 상관
≥ 0.9, 2위 후보와 비용 차 ≥ 2)에서 크기 · 검출 채널 밝기 · RI 평균 · RI 최대 · 모양(이심률)이 같은 입자와
다른 입자 사이에서 얼마나 다른지 배워 가중치를 정하고, 그 가중치로 2차 연결을 합니다 (밝기 / 크기 가중치
대신).

- **위치 예측** 칩 (여러 개 켤 수 있음):
  - **세포 움직임**: 세포 채널의 optical flow로 세포에 실려 가는 이동을 더합니다.
  - **주변 패턴 매칭**: 입자 주변 배치를 템플릿으로 다음 프레임에서 찾습니다 (점수가 낮으면 작은 템플릿으로
    다시).
  - **트랙 속도 (Kalman)**: 트랙 자체의 속도로 예측하고, 예측이 빗나간 만큼 그 트랙의 gate를 넓힙니다.
- **최대 이동 (gate)** 1.55 µm, **최대 gate** 2.48 µm: 예측 위치에서 이보다 먼 검출은 잇지 않습니다
  (ParticleTracker의 10 / 16 HT px).
- **누락 프레임 연결** 2 프레임 (v0.70부터 기본 2, ParticleTracker 기본은 1): 검출이 잠깐 빠져도 앞뒤 조각을 한
  트랙으로 잇습니다. 1 프레임이면 ParticleTracker의 1 프레임 방법(끝 위치를 두 프레임 앞으로 외삽, gate × 1.3),
  2 이상이면 ParticleTracker의 close_gaps(앞 · 뒤 외삽, gate × √(누락 + 1), 끝 · 시작 3 시점의 외형, 연결
  묶음마다 최적 할당)를 그대로 씁니다.
- **밝기 / 크기 차이 가중치**: 비용에서 |ln(비)|에 곱하는 값.

## 3 측정

- 채널마다 입자 ROI 평균 − ROI 둘레 고리(0.34–0.9 µm, ParticleTracker의 형광 3–8 px)의 중앙값 (고리에서
  다른 입자는 뺌).
- **비율**: B / A 채널 (예: 형광 B / 형광 A). 입자가 합쳐지거나 가려진 시점(면적 1.8배 또는 밝기 1.6배
  이상 변화)은 **합쳐짐 / 가림 시점은 비율에서 제외**가 켜져 있으면 비율을 비웁니다.
- **세포 안 기준**: 프레임의 50 %를 넘게 세포 안에 있으면 「세포 안」 트랙 (ParticleTracker와 같은 기준).
- **긴 트랙**: 10 프레임 이상. 더 짧은 트랙은 「짧은 트랙」.

## 5 신호 기준 (긴 트랙, v0.72)

세포 안 / 밖 대신, 긴 트랙을 한 채널의 신호가 있는 트랙과 없는 트랙으로 나눕니다 (예: pHrodo green이 켜지는 입자).

- **신호 있는 트랙으로 나누기**: 켜면 4 트랙의 칩과 요약, 데이터 표(`class` = `signal` / `nosignal`), 그래프, 일괄 분석, 내보내기가 이 두 그룹을 씁니다. 끄면 원래대로 세포 안 / 밖.
- **채널**: 기본은 추적의 측정 채널 (ParticleTracker 방식이면 measure).
- **히스토그램 · Min = 신호 기준 · Max**: LUT 탭의 그 채널 Min / Max와 같은 값입니다. 여기서 움직이면 LUT 탭과 미리보기가 같이 바뀌고, LUT 탭에서 바꿔도 여기 값이 바뀝니다. Min 아래는 화면에서 검게 보이므로 보면서 기준을 잡을 수 있습니다. Auto, Min/Max, 전체 이미지에 적용은 LUT 탭과 같습니다. 기준은 이미지마다 그 이미지의 Min입니다.
- **기준 값**: 입자 ROI 최댓값 (밝은 픽셀이 하나라도 Min 이상) 또는 입자 ROI 평균.
- **신호 프레임**: 이 수 이상의 프레임에서 기준 값 ≥ Min이면 신호 트랙 (기본 3). 긴 트랙 기준은 3 측정의 긴 트랙 (기본 10 프레임).
- **미리보기**: 지금 프레임에서 신호 트랙의 입자에 초록 고리 (Min 이상) 또는 흰 점선 고리 (Min 아래).
- 값: ParticleTracker 방식의 측정 채널 최댓값은 추적 결과(`I_B_max`)를 그대로 쓰고, 다른 채널 · 평균은 트랙 값이나 이미지에서 입자 윤곽으로 잽니다 (처음 한 번, 프레임마다 읽음).
- 내보내기 › 입자 추적 › 신호 기준: 이미지마다 `<이름>_signal_thr<Min>/` (트랙 요약 · 시점 CSV, 비교 그래프 = 중앙값 ± IQR의 ratio · 신호 값, 신호 트랙 시간 곡선), 모든 이미지 `신호 기준 통합/` (통합 그래프, `per_image_summary.csv`, 이미지별 비율).

## 4 트랙

- 상태 줄: 트랙 수, 긴 트랙 (세포 안 / 밖), 누락 연결, 합쳐짐 시점.
- **세포 안 / 세포 밖 / 짧은 트랙** 칩으로 표와 캔버스에 보일 트랙을 고릅니다.
- 트랙 표: 트랙, 프레임 범위, 세포, 평균 속도 (µm/min), 비율 끝 / 처음. 행을 고르면 캔버스에서 그 트랙이
  굵게 강조되고, 실시간 값 박스에 그 트랙의 비율 곡선이 나옵니다.
- **이미지에 트랙 표시**: 현재 프레임까지 최근 8 프레임의 꼬리와 현재 위치 원.
- **트랙 불러오기…**: ParticleTracker 결과 폴더의 `tracks_points` CSV (또는 이 앱이 내보낸 CSV)를 현재
  이미지에 불러옵니다. 파일 › 불러오기나 끌어다 놓기로도 알아서 불러옵니다.
- **그래프 ›**: 그래프 창에서 `입자 추적 · 시점` 표로 새 그래프 (기본: 시간 – 비율, 트랙마다 회색 선 +
  평균 ± SD).

## 6 신호 변화 트랙 (신뢰할 수 있는 트랙만, v0.73)

**켜짐 · 꺼짐 트랙 찾기**를 켜면 긴 트랙마다 **트래킹 점수**(0–100 = 100 × 연결 신뢰도 × RI 주변 연속성)를
매깁니다. 연결 신뢰도는 누락 · 합쳐짐 · 가려짐 없이 이어진 연결의 비율, RI 주변 연속성은 입자 둘레(약
4.8 µm)의 RI 모양이 이웃 프레임끼리 비슷하게 남는 비율입니다. 점수가 기준 이상인 트랙 중에서
[5 신호 기준](#5-신호-기준-긴-트랙-v072)의 Min을 트랙 안에서 넘거나 내려가는 트랙을 고릅니다.

| 항목 | 기본 | 뜻 |
|---|---|---|
| **최소 트래킹 점수** | 50 | 이 점수 이상인 트랙만 판정 |
| **신호 기준** | | 5 신호 기준의 Min (채널 = 값) |
| **신호 프레임** | 3 프레임 이상 | 신호 있는 프레임 수 |
| **연속 신호** | 2 프레임 이상 | 그중 연달아 있는 프레임 수 |
| **다른 입자가 스쳐 간 시점은 빼고 다시 판정** | 켬 | 신호 있는 다른 입자가 닿은 프레임(중심 거리 < 두 반지름 + 2 px)과 합쳐진 점을 빼고 판정 |
| **세포 안 트랙만 (세포질 50 % 넘는 프레임)** | 켬 | |

유형 칩 **켜짐**(꺼져 있다가 켜짐) · **켜짐→꺼짐** · **꺼짐**(켜져 있다가 꺼짐)으로 고른 유형만 이미지와
표에 보입니다. 이미지에서 실선 고리 = 그 프레임 신호 있음, 점선 = 없음.

내보내기 › 입자 추적 › **신호 변화 트랙**: 이미지마다 `<이름>_signal_change/`에 유형별 폴더(트랙 CSV +
점수 + 시간 곡선), 모든 이미지는 `신호 변화 통합/per_image_change.csv`와 점수 분포 그래프.
[파이프라인](24-pipeline.md)의 프리셋 **ParticleTracker 신호 기준**도 같은 판정을 씁니다.

## ParticleTracker 기본값

이 탭의 초기값은 ParticleTracker 1.11의 기본값을 µm로 옮긴 값입니다 (HT 1 px = 0.155 µm, 형광 1 px =
0.112 µm): gate 1.55 µm, 최대 gate 2.48 µm, gate 배수 4, 속도 α 0.4, 세포 불일치 2, 밝기 3, 크기 1.5,
이웃 일관성 1 (반경 2.8 µm, 최소 2개), 패턴 반폭 1.7 µm · 탐색 1.35 µm · 상관 0.5 / 0.4, 2단계 반폭 0.56 µm ·
탐색 2.7 µm · 최소 상관 0.5 · 가중치 0.5, 누락 연결 1 프레임, 외형 특징 켬, 고리 0.34–0.9 µm, 최소 I(A) 5,
긴 트랙 10 프레임, 세포 안 50 %, 합쳐짐 1.8배 / 1.6배 / 3 프레임, 합쳐짐 시점 비율 제외, Z 최대 투영. 다른 점은
누락 프레임 연결 하나입니다 (이 앱 2, ParticleTracker 1).

**ParticleTracker와 같게**를 끈 경우 다른 점: 입자 검출은 입자 ROI 탭의 방법을 쓰고 (ParticleTracker 방식을
고르면 같은 검출), 형광을 HT 격자에 맞춘 영상에서 찾으며, 형광 → RI 정합은 TCF 정보로 고정입니다. 학습된 연결
모델, 주변 배치 비교(기본 꺼짐), 분열 세포 제외, 퍼진 세포막 구분은 이 방식에는 없습니다.

## ParticleTracker 결과 폴더 (v0.71)

파일 › 내보내기 › 입자 추적 › **ParticleTracker 결과 폴더**(기본 켜짐)는 이미지마다 `<이름>_ParticleTracker/`에
ParticleTracker가 결과 폴더에 쓰는 것과 같은 파일을 같은 이름 · 열 · 반올림으로 씁니다. 그래서 ParticleTracker의
통합 분석 · 특이 입자 · 그룹 비교 탭이나 그 CSV를 읽던 스크립트에 그대로 넣을 수 있습니다.

| 파일 | ParticleTracker와 같게 | 이 앱 방식 |
|---|---|---|
| `tracks_points_A_B_HT.csv` (트랙 × 시점, 40열) | 같음 (바이트까지) | 같은 열 (형광 좌표 = 화면 좌표, 정합 · 퍼진 세포막 · 분열 · HT 확인 열은 빈 값 / False) |
| `tracks_summary_A_B_HT.csv` (트랙 요약) | 같음 | 같은 열 (ParticleTracker의 요약 코드로 계산) |
| `particles_all_slices.csv`, `summary_per_slice.csv` (검출) | 같음 | 같은 열 (둘레 · 최대 · 최소 밝기, threshold는 빈 값) |
| `particles_per_cell.csv` | 같음 | 같은 열 (세포 면적은 빈 값) |
| `registration.csv`, `footprint_per_frame.csv`, `cell_stats_mitosis.csv`, `cell_intensity.csv`, `particle_labels.tif`, `tracking_appearance_weights.json` | 같음 | 없음 (이 방식에는 없는 단계) |
| `dataset.json`, `config_used.yaml` | 같은 형식 | 같은 이름 (이 앱 설정) |
| 그래프 PNG 9종 (`ratio_timecourse_inside.png` …) | ParticleTracker 그래프 코드 그대로 | 없음 |
| 영상 MP4 7종 (`movie_reference_inside.mp4` …, 기본 꺼짐) | ParticleTracker 영상 코드 그대로 | 없음 |

ParticleTracker의 `_cache/` 폴더(다시 실행용 중간 결과)는 쓰지 않습니다. 그래프와 영상은 TCF 파일을 다시 읽어
만듭니다.
