# 측정 데이터 보기 (v0.64)

탭은 "무엇을 잴지 정하고 재는 곳", 그래프 창은 "잰 데이터를 보는 곳"입니다.

## 측정 탭의 두 카드

세포질 ROI · 입자 ROI · 강도 측정 · 등거리 띠 탭은 모두 같은 두 카드로 끝납니다.

- **측정 항목**: 세기 (채널마다) 칩(Mean, StdDev, Min, Max, IntDen, RawIntDen), **측정할 채널** 칩
  (채널 이름으로 기억), **LUT에서 숨긴 채널 제외**.
- **데이터**: 맨 위 상태 한 줄(예: 「12 이미지 중 12개 측정됨」, 「… 다시 측정해야 합니다」)과 탭이
  만드는 표마다 한 줄 — 이름(「기능 · 점 하나」, 예: `입자 ROI · 세포`, `입자 ROI · 그룹 요약`), 행 수 ·
  이미지 수, 상태(최신 / 설정 바뀜), **그래프 ›**(그래프 창에서 이 표로 새 그래프). 버튼은 **모든 이미지
  측정**과 **현재 이미지만**입니다.

인스펙터의 결과 표와 자동 갱신은 없어졌습니다. ROI나 측정 항목이 바뀌면 그 이미지의 표가 「설정 바뀜」이
되고, 다시 재는 때는 측정 버튼을 누를 때와 그래프 창에서 그 표를 열 때(바뀐 이미지만)입니다.

## 값을 보는 곳

- **ROI 위 값**: 측정 탭이 보일 때 세포 ROI에 마우스를 올리면 이름 · 면적 아래에 그 세포의 측정값이
  보입니다(현재 이미지만 계산).
- **탭 칩의 빨간 점**: 그 탭의 표에 행이 있으면(모든 이미지 기준) 칩에 빨간 점이 찍히고, 칩에 마우스를
  올리면 어떤 표가 몇 행인지 나옵니다.
- **실시간 값 박스**: 캔버스 아래(T 슬라이더 밑)의 카드. 현재 이미지 · 시점만 계산해 큰 숫자(이전 값과의
  차이 포함)와 작은 그래프를 보여 주고, ⌄로 접습니다.

  | 탭 | 숫자 | 그래프 |
  |---|---|---|
  | 세포질 ROI | 세포, 크기 범위 밖, 가장자리 세포, 핵 없는 세포 | 세포 면적 분포 |
  | 입자 ROI | 입자, 세포당 입자, 면적 중앙값, 작은 조각 (노이즈 의심 표시) | 입자 면적 분포 |
  | 강도 측정 | 영역 넓이 | — |
  | 등거리 띠 | 띠, 잰 세포 | 세포마다 띠별 세기 (고른 세포 빨강) |
  | FRAP | 이동 분율, t½, 현재 시점 회복, 최대 드리프트 | 회복 곡선 (탭에서 옮겨 옴) |
  | 라인 프로파일 | 선 길이, 채널별 최대 | 채널별 강도 (탭에서 옮겨 옴) |
  | Coloc 2 | Pearson r, Manders M1 / M2 | 고른 ROI의 그림 (탭에서 옮겨 옴) |

- **그래프 창 › 데이터 목록**: 왼쪽 위에 기능별 표(행 수, 설정 바뀜 표시)가 있고, 누르면 새 그래프(종류 →
  축 배치 → 그룹)가 열립니다. 맨 아래 **CSV 불러오기…**. 그래프 위에는 「표 · 행 · 이미지 · 그룹 · 열」
  머리글, 아래 표 콤보에는 **열 설명**(열, 표시 이름, 종류, 단위, 뜻, ImageJ / 출처)이 있습니다.
- **측정 현황 · 일괄 분석** (View 메뉴, 파일 › 측정 현황 · 일괄 분석…): 그룹별 이미지 × 데이터 표, 칸마다
  최신 · n행 / 설정 바뀜 / 빈칸. 두 번 누르면 그 이미지를 그 탭에서 열고, 오른쪽 클릭하면 그 칸만 다시
  잽니다. 도구 막대: **그룹 · 분석 고르기…**, **일괄 분석 실행**, **바뀐 것 다시 측정 (n)**, **내보내기…**.
  예전의 일괄 분석 결과 창을 대신합니다.
