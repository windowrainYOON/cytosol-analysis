# 그래프 편집 창

[← 설명서 목차](README.md) · [English](../en/16-graph.md)

기능 탭의 그래프를 한 창에서 열어 모양을 마음대로 고칩니다. 그래프는 모두 이 창 하나의
사이드바에 모이고, 저장은 **파일 › 내보내기…**의 **그래프** 항목에서 합니다.

## 여는 방법

- **그래프 › 현재 탭의 그래프 편집 창** (`Ctrl+G`): 오른쪽에 보이는 탭의 그래프
- **그래프 ›** (기능 이름): 결과가 있는 기능의 그래프를 탭에서 보던 모양 그대로
- 그래프 편집 창 위쪽의 **새 그래프** 칩: 분석 결과로 새 그래프를 단계별로 만듭니다 (아래).

| 기능 | 처음 보이는 그래프 |
|---|---|
| FRAP 측정 | 탭에서 고른 그래프 그대로: 회복 곡선 + 피팅, ROI 평균 강도, 그룹 평균 ± SEM/SD (+ 개별 곡선, 피팅) |
| 라인 프로파일 | 채널마다 한 선 (채널 색, LUT에서 숨긴 채널 제외, 0–1 정규화 설정 그대로) |
| 등거리 띠 | 세포마다 회색 선 + 빨간 평균 ± SD 띠 (탭에서 고른 x·y) |
| 세포질 ROI · 입자 ROI · 강도 측정 결과 표 | 첫 평균값 열(입자마다 측정이면 면적)의 막대 그래프 (평균 ± SD, 개별 값 점), 그룹·이미지·영역·ROI별 |
| Coloc 2 | 선택한 ROI의 2D 히스토그램을 히트맵으로 (회귀선, threshold 선). 결과 이미지를 보고 있었다면 ROI별 Pearson R 막대 |

창을 다시 열거나 **편집 › 도구의 현재 결과 다시 불러오기** (`Ctrl+R`)를 누르면 탭의 최신
결과로 데이터를 바꿉니다. 열 이름이 그대로면 고친 설정은 그대로 둡니다. **편집 › 처음
그래프로 되돌리기**는 모든 설정을 처음 그래프로 되돌립니다.

## 새 그래프 만들기 (단계 창)

위쪽 **새 그래프** 칩은 분석(세포질 ROI 측정, 입자 ROI 측정, 강도 측정, 등거리 띠, Coloc 2,
라인 프로파일, FRAP, 일괄 분석 결과)마다 하나이고, 맨 끝의 **CSV…**는 CSV 파일(첫 줄 = 열
이름; 쉼표, 세미콜론, 탭)을 씁니다. 아직 분석하지 않은 기능의 칩은 흐리게 보이고, 마우스를
올리면 무엇을 먼저 하면 되는지 나옵니다. 칩을 누르면 **새 그래프** 창이 열리고, 오른쪽
미리보기를 보면서 세 단계를 차례로 정합니다.

1. **그래프 종류**: XY (선 · 점), 막대, 점 그림, 상자 그림, 바이올린, 히스토그램, 히트맵.
   표의 열을 보고 맞는 종류에 **추천**이 붙습니다 (글자 열이 있으면 범주 비교, 숫자 두 열이면 XY).
2. **축 배치**: **데이터 표**, **X 축**과 **Y 축**마다 **범주 / 값**과 열.
   - **범주**: 같은 값끼리 한 자리에 모읍니다 (그룹, 이미지 …). **값**: 숫자 눈금 위에 놓습니다.
     글자 열은 범주로만 씁니다. 두 축 모두 어떤 열이든 놓을 수 있습니다.
   - 막대 · 점 그림 · 상자 · 바이올린은 한 축이 범주입니다. X를 값으로 바꾸면 축이 서로 바뀌어
     범주가 세로(Y)로 가는 가로 그래프가 됩니다.
   - **Y 축에는 열을 여러 개** 놓을 수 있습니다 (**＋ Y 열 추가**, 줄 끝 ×로 빼기). 열마다 색이 다른
     시리즈가 됩니다.
   - **색으로 나누기**: 나누지 않음, **Y 열마다**, 또는 글자 열 (그 열의 값마다 색이 다름; X 축
     범주와 같은 열이면 범주마다 색).
   - **에러바** (SD / SEM / 95 % CI / 없음), XY에서는 **같은 x 묶기** (평균 / 중앙값).
3. **그룹**: 범주 축의 열(없으면 색으로 나누는 열)의 값마다 한 줄 (값, n). 체크한 그룹만 그리고,
   줄을 끌어 그래프에서의 순서를 바꿉니다. **모두** / **없음**.

**그래프 만들기**를 누르면 사이드바에 새 그래프가 생깁니다. 세 단계는 언제든 인스펙터의
**데이터** 탭에서 다시 바꿀 수 있습니다.

## 창 구성

- **사이드바**(왼쪽): 이 창의 그래프 목록. 더블클릭 = 이름 바꾸기, 우클릭 = 새 그래프 · 복제 ·
  이름 바꾸기 · 맨 아래 빨간 **그래프 삭제…**.
- **가운데 상자**: 위에 **새 그래프** 칩, 가운데 그래프 미리보기(저장할 크기와 같은 비율),
  아래 데이터 표: **그래프에 쓰인 데이터**(그려진 점마다 한 행), 막대 · 상자 등에서는
  **그래프 요약**(n, 평균, SD, SEM, 중앙값, 최소, 최대), 그리고 기능이 넘겨준 모든 결과 표.
  셀을 골라 `Ctrl+C`(macOS `⌘C`)로 복사. 그래프와 표 사이 경계는 끌어서 바꿉니다.
- **인스펙터**(오른쪽, 폭 고정): **데이터** / **모양** / **통계** 탭.
  - **데이터**: 그래프 종류 카드, **축 배치**, **그룹** (단계 창과 같은 내용). 기능 탭에서 연
    그래프는 탭이 만든 구성으로 시작하고, 축 배치를 바꾸면 고른 표로 다시 그립니다 (피팅 곡선처럼
    다른 표의 선은 그대로 남음).
  - **모양**: **색**(시리즈마다), **점 · 선**, 막대 · 히스토그램 · 히트맵 설정, **축**(X 축 / Y 축
    칩), **제목**, **범례**, **글꼴**, **그림**, **글자 상자**. 그래프에서 제목, 축 이름, 범례, 점이나
    막대, 글자 상자를 누르면 그 카드로 바로 갑니다.
  - **통계**: 유의성 표시 (아래).

## 그래프 위에서

**그래프 영역**, **제목**, **X·Y 축 이름**, **글자 상자**, **범례**는 모두 고르고 옮기고
크기를 바꿀 수 있는 오브젝트입니다.

- **클릭**: 고름 (파란 점선 상자). **끌기**: 옮기기.
- **오른쪽 아래 파란 핸들 끌기**: 크기. 그래프 영역은 너비·높이 (위 가장자리 고정), 글자는
  글꼴 크기 (축 이름은 X·Y가 같은 크기).
- 자동 배치인 것을 처음 끌면 지금 자리에서 직접 놓기로 바뀝니다. **모양 › 그림**의 **모두 자동 배치로**나
  오른쪽 클릭 › **모든 위치·크기 자동 배치로**로 되돌립니다.
- **두 번 클릭**: 글자 상자, 제목, 축 이름, 범례 항목 이름 고치기.
- **오른쪽 클릭**: **여기에 글자 상자 추가…**, **범례를 여기로 옮기기**, **범례 항목 추가**,
  **이 글자 상자 지우기**.

### 미리보기 확대·축소 (현미경 미리보기와 같음)

- `Cmd`(Windows `Ctrl`) + 왼쪽 버튼 위아래 드래그, `]` 확대 / `[` 축소, `Cmd`(`Ctrl`) + 휠.
- **화면 맞춤** (`Ctrl+0`), 미리보기 위의 **－ ＋** 버튼. 배율은 옆에 표시.
- 이동: 가운데 버튼 드래그, 휠 (위아래), `Shift` + 휠 (좌우). 드래그 감도는 설정의 확대
  감도를 따릅니다. 확대는 미리보기만 바꾸고 저장할 그림 크기는 그대로입니다.

## 모양

### 그래프 종류별

- **점 · 선**(모든 시리즈): 그리기 방식(XY: 선 + 점, 선, 점, 계단, 면적), 선 모양, 선 굵기,
  점 모양, 점 크기, 점 속 채우기, 불투명도, 에러바 모양(에러바 / 띠 / 없음), 굵기, 캡.
- 막대 · 점 그림 · 상자 · 바이올린: **개별 값을 점으로 표시**, 폭, 채움 투명도, 점 흩뿌림.
  히스토그램: 구간 수 (자동), 밀도, 채우기. 히트맵: 색 지도, 로그 색 눈금, 색 막대.
- 범주 축의 그룹 안에서 시리즈가 여럿이면 나란히 놓고, 한 범주에 시리즈가 하나뿐이면(색 =
  범주) 가운데 놓습니다.

### 축

**X 축** / **Y 축** 칩으로 고른 축의 **이름**, **단위**, **단위 바꾸기**, **범위 자동**과 최소 · 최대,
**눈금 간격 자동**과 간격, **로그 눈금**, **보조 눈금**, **눈금 방향**, **눈금 글자 회전**,
**값 배율**. 자동일 때도 칸에는 지금 쓰는 범위와 간격이 보이고, 자동을 끄면 그 값에서 시작합니다.

- **단위**: 축 이름 뒤 괄호에 붙습니다 (`Time` + `min` → `Time (min)`; 이름 끝에 이미 괄호
  단위가 있으면 바꿈). 목록에 없는 단위는 직접 입력.
- **값 배율 (×)**: 그릴 때 값에 곱하는 수 (`1/60` 같은 분수도 됨). **단위 바꾸기** 목록
  (s → min, min → s, s → ms, min → h, 0–1 → %, % → 0–1, µm → nm, nm → µm)은 배율과 단위를
  함께 정합니다. 배율을 바꾸면 직접 정한 최소 · 최대 · 간격도 같이 바뀝니다.

### 제목 · 범례 · 글꼴 · 그림 · 글자 상자

- **제목**: 글자, 크기, 색, 굵게, 기울임.
- **범례**: 표시, **위치**(자동, 그래프 위, 그래프 오른쪽, 안쪽 네 모서리, 직접 놓기), 제목, 열 수,
  테두리, 글꼴. 이름은 범례 항목을 두 번 클릭해 고칩니다. 시리즈와 상관없는 항목도 추가할 수
  있습니다 (이름, 색, 점 모양).
- **글꼴**: 글꼴(비우면 기본, 한글은 자동으로 한글 글꼴), 축 이름 크기 · 굵게, 눈금 글자 크기,
  글자 · 축선 색.
- **그림**: 가로 × 세로 (인치), 해상도 (dpi), 배경, 위 · 오른쪽 축선, 축선 · 눈금 굵기, 격자와
  격자 색, **그래프 영역 자동 배치**, **모두 자동 배치로**.
- **글자 상자**: 목록, 추가, 빨간 **삭제…**, 글자(여러 줄), 크기, 색, 굵게, 테두리, 정렬.

## 통계 · 유의성 표시

막대 · 점 그림 · 상자 · 바이올린 그래프에서 범주끼리 비교해 괄호와 별표(\*)를 그립니다.
인스펙터 **통계** 탭의 **유의성 표시** 스위치로 켜고, **통계 창 열기…**(또는 **편집 › 통계 ·
유의성 표시…**)는 같은 설정을 미리보기와 함께 큰 창에서 정합니다(**적용**을 눌러야 그래프에
들어감). 계산은 SciPy로 합니다.

- **데이터 확인**(창): 그룹마다 n과 정규성(Shapiro-Wilk, n < 3은 확인 불가), 등분산(Levene).
- **검정**: 데이터를 보고 **추천**을 보여 줍니다.
  - 2개 그룹: 정규 + 분산 비슷 → t-검정, 정규 + 분산 다름 → Welch t-검정, 정규가 아님 →
    Mann-Whitney U.
  - 3개 이상: 정규 + 분산 비슷 → One-way ANOVA + Tukey, 정규 + 분산 다름 → Welch ANOVA +
    Games-Howell, 정규가 아님 → Kruskal-Wallis + Dunn.
  - **표본**이 짝지음(같은 세포 · 이미지)이면 짝지은 t-검정 또는 Wilcoxon 부호 순위.
  - **비교할 값**: Y 열(또는 시리즈)이 여럿이면 어느 것의 범주끼리 비교할지.
  - **방법**: 추천(기본) 또는 직접 고르기. **꼬리**: 양측(추천), 단측(비교 그룹 > 기준 / < 기준;
    실험 전에 방향을 정해 둔 경우에만). ANOVA · Kruskal-Wallis의 사후 검정은 양측만.
  - **다중 비교 보정**: Holm(기본), Bonferroni, Benjamini-Hochberg (FDR), 없음. Tukey와
    Games-Howell은 자체 보정을 씁니다. **유의 수준 α**: 0.05 / 0.01 / 0.001.
- **비교할 쌍**: **모든 쌍**, **기준 대 나머지**(기준 그룹), **직접 고르기**(표에서 체크). 표에는
  쌍마다 보정한 p와 표시가 나옵니다.
- **표시**: 별표 / p 값 / 둘 다, 별표 기준(4단계 \* < 0.05, \*\* < 0.01, \*\*\* < 0.001,
  \*\*\*\* < 0.0001 또는 3단계), ns 표시, 괄호(꺾쇠 / 직선), 선 굵기, 글자 크기, 굵게,
  **캡션 문장**(예: “One-way ANOVA with Tukey's post hoc test (two-tailed), n = 10 per group; …”,
  **캡션 복사**).

표시 모양의 초기값(표시 방식, 별표 기준, ns, 꼬리, α, 괄호 모양 · 굵기 · 끝 길이 · 간격, 글꼴,
글자 크기, 굵게, 캡션)은 **Preferences › 그래프 · 유의성 표시 초기값**에서 정합니다. 검정 방법은
데이터마다 추천하므로 초기값이 없습니다.

## 저장

그래프 이미지(PNG / TIFF / PDF / SVG)와 데이터 CSV, 설정 JSON은 **파일 › 내보내기…**의
**그래프** 항목에서 사이드바의 그래프를 골라 저장합니다([내보내기 창](17-export.md)).
이 창의 **파일 › 내보내기…**는 그 창을 **그래프**만 켜서 엽니다. **파일 › 그래프 설정
불러오기 (전체)** / **스타일만 불러오기**로 저장한 설정(`format: cytosol-viewer-graph`)을
다른 그래프에 씁니다. CSV는 Excel에서 바로 열리는 UTF-8 (BOM)입니다.

아직 없는 기능(기준선, 피팅 곡선 직접 추가, 보조 y축)은 메뉴에 나오지 않습니다.

## 상관 분석 (v0.63)

어떤 표에도 쓰는 상관 도구입니다 (mitoROI, 입자 ROI, 측정 표, 일괄 분석, CSV 모두).

- **점 하나 =** (데이터 탭, 표에 이미지 / 그룹 열이 있을 때): **행 그대로**(세포 · 입자 …),
  **이미지 평균**, **그룹 평균**. 모든 그래프 종류와 통계에 적용됩니다.
- **상관 행렬** (그래프 종류): **상관 계산** 카드에서 표, **계산**(Pearson r / Spearman ρ),
  **가로 (X) 열**과 **세로 (Y) 열**(모든 숫자 열 / 표가 주는 열 묶음 / 직접 고르기 칩; Y는 기본
  「X와 같음」 = 정사각 행렬), **log X / log Y**, **칸에 숫자**(칸 100개 이하), **거르기**(아무 글자 열 =
  값). 색은 −1 (파랑) … 1 (빨강), 계산할 수 없는 칸은 「–」입니다. 칸 위에 마우스를 올리면 r · n · p와
  계산이 안 되는 이유(n < 3, 값이 모두 같음)가 보이고, **칸을 누르면 그 두 열의 산점도가 회귀선과 함께
  새 그래프로** 열립니다. 「그래프에 쓰인 데이터」는 Y, X, Pearson r, R², p, Spearman ρ, p, n, 이유의
  긴 표입니다.
- **상관 비교** (그래프 종류): **그룹 열**(아무 글자 열)의 값마다 상관 행렬을 만들어 비교합니다.
  **비교 › A 대 B**: A · B 행렬과 Δ (B − A), Fisher z 검정 별표(* p < 0.05, ** p < 0.01); 데이터 표는
  |Δ|가 큰 순서. **모든 그룹**: 그룹마다 작은 행렬과 그룹 사이 차이(Cochran Q) 지도.
  **다중 비교 보정**은 기본 **없음**(Mito Analyzer와 같음), Holm / FDR을 고를 수 있고, 칸 수와 우연히
  기대되는 개수를 함께 보여 줍니다.
- **XY 회귀 · 사분면** (통계 탭, XY 그래프): **회귀선**(최소제곱 / log 값으로 맞춤 / 원점 통과),
  **글자**(r, R², p, ρ, n), **색마다 선 하나**, **사분면**(평균 / 중앙값에서 I–IV와 점 개수).
- **편집 › 여러 열 그룹 요약표 저장 (CSV)…**: 숫자 열(상관 그래프는 가로 열)마다 그룹별 n, 평균, SD,
  SEM, 95 % CI, 중앙값, 사분위와 그룹 사이 검정(2그룹: Welch t, Mann-Whitney U; 3그룹 이상: ANOVA,
  Kruskal-Wallis) p.
