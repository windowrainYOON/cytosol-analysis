# 통합 데이터 (v0.68)

여러 기능에서 잰 값을 한 표에서 보려고 따로 합치는 과정은 없습니다. 측정할 때마다 결과가 **측정 범주**별
표에 저절로 들어갑니다. 다시 재면 그 이미지의 행만 바뀌고, 아무것도 새로 재지 않습니다(각 탭이 이미 가진
결과로 만들므로 원본 표와 늘 같은 값입니다).

## 범주 (점 하나 = 무엇)

| 표 | 점 하나 | 들어오는 기능 |
|---|---|---|
| 통합 · 이미지별 | 이미지 | 세포 평균, 입자 수, FRAP 피팅(Mobile fraction, t½ …) |
| 통합 · 세포별 | 세포 | 세포질 ROI, 입자 ROI(세포별), 강도 측정, Coloc 2, mitoROI(세포), 입자 추적(세포 요약) |
| 통합 · 세포 × 띠별 | 세포의 등거리 띠 하나 | 등거리 띠 측정 + 띠 넓이, 띠 안의 입자 수 · 밀도 · 평균, 띠 안의 미토 조각 수 · 길이(MiNA) · 분기점 · 끝점 · 점 수 |
| 통합 · 입자별 | 입자 | 입자 ROI(입자마다): 형태, 강도, 분배계수 + 그 입자의 세포와 띠 |
| 통합 · 미토 조각별 | 미토 조각 | mitoROI(조각): 길이, 가지, 면적, green + 세포, 띠, network / individual |
| 통합 · 시점별 | 시점 | 입자 추적(세포 × 시점), FRAP 회복 곡선 |

- 열 이름은 `기능 › 열`입니다(예: `입자 ROI › area_um2`, `mitoROI › footprint_fraction`). 앞의 키 열
  (image, image_id, group, cell, band, particle, mito, frame)로 행이 이어집니다.
- 입자 · 미토 조각 · 분기점 · 끝점 · 점은 위치로 세포와 띠를 정합니다(띠는 등거리 띠 탭 설정). 띠에 아무것도
  없으면 0입니다(그 이미지를 쟀을 때).
- 시점이 있는 측정은 세포별 표에 첫 시점 값을 넣고, 시점마다의 값은 시점별 표에 있습니다.

## 어디서 보나

- **측정 탭의 데이터 카드**: 「측정하면 통합 데이터의 … 표에 저절로 들어갑니다」 줄이 이 탭이 채우는 범주를
  알려 줍니다.
- **그래프 편집 창 › 데이터**: 맨 위가 **통합 데이터**(표마다 행 수와 「설정 바뀜」), 그 아래 접힌
  **기능별 표 (원본)**에 탭마다의 표가 그대로 있습니다. 통합 표를 누르면 새 그래프(종류 → 축 배치 → 그룹)가
  열리고, 축 배치의 열 목록은 기능별로 묶여 있습니다. 설정이나 ROI가 바뀐 이미지는 열 때 그 이미지만 다시
  잽니다.
- **그래프 메뉴 › 통합 데이터에서 새 그래프…**.
- 여러 기능의 값으로 **상관 행렬**(히트맵)도 그릴 수 있습니다: 그래프 종류에서 상관 행렬을 고르면 열 묶음이
  기능별로 나뉘어 있어 기능 하나 또는 여럿을 골라 서로의 상관을 봅니다(mitoROI 탭의 상관 히트맵과 같은
  계산).

## 내보내기

**파일 › 내보내기…**의 맨 위 항목 **통합 데이터**(기본 켬)가 내보내기 폴더 맨 위에 범주마다 CSV를
씁니다: `integrated_images.csv`, `integrated_cells.csv`, `integrated_cell_bands.csv`,
`integrated_particles.csv`, `integrated_mito_fragments.csv`, `integrated_timepoints.csv`(행이 있는 것만)와
열 설명 `integrated_columns.csv`(표, 열, 기능, 원본 열, 계산: 그대로 / 세포 평균 / 입자 평균 / 띠 안의
개수 · 평균). 고른 이미지의 행만 씁니다. 기능마다의 원본 CSV는 지금처럼 그 기능 항목에서 따로 고릅니다.
