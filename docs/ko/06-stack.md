# 스택 탭 (Z 투영과 3D 보기)

[← 설명서 목차](README.md) · [English](../en/06-stack.md)

메뉴 막대의 **스택 › 스택 탭 열기**로 오른쪽에 이 탭을 열고 닫습니다. 이 탭의 저장과 불러오기도 같은 **스택** 메뉴에 있습니다.

이 탭을 열어 두는 동안 이미지 칸에는 슬라이스 대신 투영 결과가 나옵니다. Z
스택이 있는 이미지가 필요하며, 탭을 열면 스택 전체를 읽고(**Z 스택 불러오는
중…**) 다 쓰면 메모리에서 내립니다.

## 투영 종류

- **2D projection (스택을 한 장으로)**: Z 범위를 한 장으로 합칩니다.
- **3D projection (돌려 보기)**: 볼륨을 각도만큼 돌려서 투영합니다.

## 범위

- **Z 슬라이스**: 첫–마지막 슬라이스. **전체**는 모든 슬라이스.
- **선택한 Crop 영역만 (빠름)**: **Crop** 탭(**Crop › Crop 탭 열기**)의 목록에서 고른 영역만 투영합니다.

## 2D projection

**방법**: Max intensity, Average intensity, Sum slices, Min intensity, Standard
deviation, Median (ImageJ Z Project와 같은 종류).

## 3D projection

| 항목 | 의미 |
|---|---|
| **방법** | 시선 방향으로 Brightest point (max) 또는 Mean value |
| **회전축** | **Y축 (좌우로 돌리기)** 또는 **X축 (위아래로 기울이기)** |
| **각도** | −180°–180°, 슬라이더나 숫자 |
| **Z 간격** | **자동**(메타데이터의 voxel Z / 픽셀 크기, 아래에 계산값 표시) 또는 **수동**(µm). 파일에 Z 간격이 없으면 자동은 픽셀 1개 간격이므로 실제 간격을 직접 넣으세요. |
| **미리보기** | 미리보기 해상도: **빠름 (~256 px)**, **보통 (~400 px)**, **선명 (~600 px)**, **원본 해상도** |
| **새로고침 (LUT 반영)** | Min/Max/Gamma를 바꾼 뒤 누르면 3D에 반영됩니다(LUT가 바뀌면 버튼이 강조됨). 색과 표시는 바로 반영됩니다. |

이미지 위에서 **왼쪽 드래그**는 위치 이동, **오른쪽 드래그**는 회전(좌우 = Y축,
위아래 = X축)입니다.

3D 구조는 이미지·Z 범위·Crop·미리보기 해상도·시점마다 한 번만 만들고, 돌릴
때는 다시 투영만 합니다(약 0.05초).

## LUT (투영 이미지)

- **LUT 탭과 연동 (한쪽에서 바꾸면 양쪽에 반영)**: 변경이 양쪽에 반영됩니다. Sum
  투영은 슬라이스 수만큼 범위를 곱해 적용합니다.
- 끄면 이 투영만의 LUT를 여기서 따로 조절합니다.
- **LUT 탭에서 다시 가져오기**.

## 저장

메뉴 막대의 **스택** 메뉴에서 고르면 저장 옵션 창(아래 옵션)이 뜹니다.

- **현재 투영 저장 (TIFF / MP4)…**: LUT와 마커가 들어간 RGB 이미지와, 투영값을
  담은 float32 ImageJ 스택. **타임시리즈는 모든 시점 저장**을 켜면 시점마다
  투영해 저장합니다.
- **3D 회전 시리즈 저장 (TIFF 스택 / MP4)…**: **회전** 시작 → 끝 각도,
  **간격**으로 TIFF 스택을 만듭니다.
- 저장 창에서 형식을 **MP4 동영상**으로 고르면 시점(또는 각도)마다 한 프레임인
  동영상으로 저장합니다(**MP4 프레임 속도**, fps).
- **3D는 원본 해상도로 저장**: 미리보기 해상도 대신 원본 해상도로 저장합니다.
