# 내보내기 창

[← 설명서 목차](README.md) · [English](../en/17-export.md)

저장은 모두 **파일 › 내보내기…**(`Ctrl+E` / `⌘E`) 창 하나에서 합니다. 이미지,
Crop 영역, ROI, 측정 표, 그래프, 이미지 정보, 일괄 분석 결과, 프로젝트를 한 번에
고르고 저장합니다. 각 기능 메뉴(Tool › …)에는 탭 열기와 불러오기만 남아 있습니다.
LUT 프리셋, 마커 설정, 일괄 분석 설정 저장은 예전처럼 Tool / 파일 메뉴에 있습니다.

## 창 구성

- **위쪽 막대**: **대상**(현재 이미지 / 선택한 이미지 / 모든 이미지 / 그룹마다 하나),
  **저장 위치**와 **폴더 선택…**, 파란 **내보내기** 버튼.
- **이미지별 폴더에 나눠 저장**: 켜면 이미지마다 `<저장 위치>/<이름>_<이미지 ID>/`
  폴더에 넣습니다. 끄면 한 폴더에 모읍니다(같은 이름은 뒤에 번호).
- **왼쪽 목록**: 저장할 종류. 체크박스로 넣고 빼며, 오른쪽 숫자는 켜진 항목 수 / 전체
  항목 수입니다.
- **오른쪽 카드**: 고른 종류의 세부 항목과 형식.

고른 것은 다음에 창을 열 때 그대로 남아 있습니다(이미지 형식은 프로젝트에도 저장).

## 종류

| 종류 | 저장되는 것 |
|---|---|
| 이미지 (TIFF / MP4) | 합성 RGB, 채널별 RGB, 원본값 스택(ImageJ). 타임시리즈는 모든 시점 / 현재 시점, TIFF / MP4 / 둘 다, fps, 마커 그리기 |
| Crop 영역 | Crop 영역마다 이미지(형식은 ‘이미지’를 따름; **모든 영역** 또는 **선택한 영역만**), Crop ROI(`<이름>_crops.zip`). 점 편집으로 모양을 바꾼 영역은 둘러싼 사각형으로 자르고 바깥은 0 |
| 세포질 ROI | 세포 / 핵 / 세포질 ROI(RoiSet .zip 또는 .roi), 측정 CSV, ROI가 그려진 PNG, 등거리 띠 CSV / 그래프 |
| 입자 ROI | 입자 ROI(.zip), 측정 CSV, 이미지별 · 그룹별 요약 |
| 강도 측정 | 측정 CSV, 논리 영역 ROI |
| Coloc 2 | 결과 CSV, ROI마다 PDF 리포트 |
| 라인 프로파일 | 현재 이미지의 선: CSV, 그래프, 선 ROI + 그림 |
| FRAP | 요약 CSV + 그룹 그래프, 이미지마다 곡선 CSV / 그래프 / ROI |
| 스택 투영 | 현재 투영, 3D 회전 시리즈(TIFF 또는 MP4) |
| 그래프 | 그래프 편집 창의 그래프들(고르기), 형식(PNG / TIFF / PDF / SVG), 데이터 CSV, 설정 JSON |
| 이미지 정보 | 획득 정보 CSV, 원본 메타데이터 |
| 일괄 분석 결과 | 결과(`batch/`), 설정 JSON |
| 프로젝트 · 작업 기록 | 저장 위치를 기준으로 한 `project.cyproj`, 작업 기록 CSV |

여러 이미지에 걸친 표(`cell_rois.csv`, `coloc2.csv`, 측정 CSV, 요약,
`image_groups.csv`)는 저장 위치 맨 위에 하나씩 저장됩니다. 파일 이름은
[저장되는 파일](12-output-files.md)을 보세요.

Figure는 Figure 창 위쪽의 **Figure 저장…** / **모든 Figure 저장…**으로 저장합니다
([Figure](11-figure.md)).
