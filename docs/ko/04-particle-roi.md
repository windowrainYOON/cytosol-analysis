# 입자 ROI 탭 (점·puncta·응축체)

[← 설명서 목차](README.md) · [English](../en/04-particle-roi.md)

**Tool › 입자 ROI**를 켜면 오른쪽에 이 탭이 열리고, 끄면 닫힙니다. 결과는 **파일 › 내보내기**에서 저장합니다.

[세포질 ROI 탭](03-cytosol-roi.md)의 세포마다(또는 이미지 전체에서) 한 채널의
입자(밝은 점, puncta, 응축체)를 찾아 세포별로, 또는 입자 하나씩 측정합니다.
입자는 현재 Z 평면(또는 MIP)과 시점에서 찾고, ROI나 설정이 바뀌면 바로 다시
찾습니다.

## 1. 입자 ROI 추출

1. **이 이미지에서 입자 ROI 정의**를 켭니다.
2. **채널**: 입자 채널.
3. **찾을 영역**:
   - **세포질 (핵 제외)**,
   - **세포 전체**,
   - **이미지 전체 (세포 ROI 없이)**(세포 ROI가 필요 없음. 세포 ROI가 없는
     이미지에서는 미리 선택되어 있음).
4. **방법**:
   - **자동 (점 검출)**: scale-normalised Hessian(둥근 점에서 크고, 세포나 핵
     경계에서는 작음)과 배경을 뺀 강도가 둘 다 세포의 중앙값 + k × MAD를 넘는
     곳을 점의 중심으로 찾습니다. 그다음 배경을 뺀 이미지에서 각 점을 자기
     봉우리의 30 %까지 watershed로 넓히므로, 붙어 있는 점은 따로 나뉘고 밝은
     점 옆의 흐린 점도 남습니다.
     - **자동 민감도 (k)**(기본 3): 작을수록 흐린 점까지 찾습니다.
     - **자동 입자 지름**(기본 0.4 µm): 찾을 입자의 대표 크기로, 필터 크기를
       정합니다. 픽셀 크기 정보가 없는 이미지는 0.1 µm/px로 봅니다.
   - **수동 threshold**: 모든 세포에서 **수동 값**(숫자 칸 또는 슬라이더)
     이상인 픽셀을 8-연결 입자로 나눕니다(ImageJ Analyze Particles와 같음).
5. **최소 입자 크기**(px): 이보다 작은 입자는 버립니다.
6. **이미지에 입자 경계 표시**: 픽셀 ROI는 자홍색, 등강도선은 주황색.

### 등강도선으로 형태 측정

**형태는 등강도선으로 측정 (서브픽셀)**(기본 켜짐)과 **레벨**(기본 0.5 =
반치폭): 형태 값(둘레, 원형도, solidity, AR, roundness, Feret, 타원, 중심,
등가 지름, 최근접 거리)을 픽셀 경계 대신, 배경 + 레벨 × (봉우리 − 배경)
밝기를 잇는 서브픽셀 윤곽에서 잽니다. 배경은 그 세포에서 입자 주변 3 px 안의
빈 픽셀 중앙값, 봉우리는 0.7 px 가우시안 뒤 입자의 최대값입니다. 그래서 둥근
입자가 실제로 둥글게 나옵니다(solidity ≈ 1). 끄면 ImageJ Analyze Particles와
똑같은 값입니다.

### 강도를 잴 픽셀

**강도 측정 ROI**:

- **픽셀 ROI**(기본): 입자로 잡힌 픽셀 그대로(ImageJ Analyze Particles와 같음).
- **등강도선 ROI**: 같은 레벨의 등강도선 안에 중심이 든 픽셀(ImageJ가 polygon
  ROI를 마스크로 만드는 방식). 입자 영역, 입자를 뺀 나머지, 입자마다 행,
  분배계수, [강도 측정 탭](09-intensity.md)의 논리 영역에 모두 적용됩니다.

### 여러 이미지

- **이 설정을 모든 이미지에 적용**: 같은 이름의 채널에서 같은 방법으로 모든
  이미지의 입자를 찾습니다.
- 입자 ROI 저장 / 불러오기: **파일 › 내보내기 › 입자 ROI › 입자 ROI 저장 (현재
  이미지)…**로 저장하고, **파일 › 불러오기 (파일)…**로 다시 엽니다. `<이름>_particles.zip`, 입자마다 ImageJ ROI
  하나(`partCCC-NN`, 픽셀 경계를 따른 윤곽이라 ImageJ 마스크가 입자와 정확히
  같음. 설정은 ROI 속성에 저장). 등강도선은 옆에 `<이름>_particles_contour.zip`
  으로 저장됩니다.

## 2. 측정

### 세포별 (입자 영역 합)

세포(이미지 전체 모드는 `image`)와 영역마다 한 행, 입자 수 포함:

- **입자**: 그 세포의 입자 픽셀 전체.
- **입자를 뺀 나머지**: 찾을 영역에서 입자를 뺀 곳(`cyto - particle` 또는
  `cell - particle`, 이미지 전체는 `image - particle`).

파일: `<이름>_particle_intensity.csv`, `particle_intensity.csv`.

### 입자마다 (형태·분배계수)

입자(`partCCC-NN`)마다 한 행. 면적은 항상 들어가고, 아래 항목을 골라 넣습니다
(마우스를 올리면 정의가 보입니다).

| 항목 | 값 |
|---|---|
| 중심 X, Y | 중심 위치 |
| 둘레 | 둘레 |
| 원형도 | 4π·면적 / 둘레² (1 = 원) |
| Solidity | 면적 / 볼록 껍질 면적 (1 = 오목한 곳 없음, 낮으면 방울이 붙었거나 불규칙한 응집체) |
| 종횡비 (AR) | 맞춘 타원의 장축 / 단축 |
| Roundness | 4·면적 / (π·장축²) |
| Feret 지름 | Feret, MinFeret, Feret 각도 |
| 타원 (장·단축, 각도) | 맞춘 타원의 장축, 단축, 각도 |
| 등가 지름 | 2√(면적/π) |
| 최근접 입자 거리 | 같은 세포(또는 이미지)에서 가장 가까운 다른 입자 중심까지 거리 |
| 분배계수 | 채널마다 입자 평균 / 그 세포의 찾을 영역에서 입자를 뺀 곳(묽은 상)의 평균. 배경을 빼지 않은 원본값 |

여기에 채널마다 강도 값(Mean, IntDen, …)이 붙습니다. 등강도선 형태를 끄면
ImageJ 1.54f Analyze Particles와 값이 같습니다. 등강도선 형태를 켜면
`shape_outline`, `shape_area_um2` 열이 추가됩니다.

파일: `<이름>_particle_shape.csv`, `particle_shape.csv`.

### 이미지별·그룹별 요약

**모든 이미지 측정** 뒤 표 보기 선택에서 **요약: 이미지별**, **요약: 그룹별**을
고를 수 있습니다. 이미지 또는 그룹(세포별 모드는 영역까지)과 파라미터마다 한
행으로 `n`(입자 또는 세포 수), `mean`, `sd`(n − 1), `min`, `max`를 주고, 그룹
행에는 `n_images`가 붙습니다. 저장하면 `<suffix>_summary_image.csv`,
`<suffix>_summary_group.csv`가 생깁니다. 그룹은 이미지 목록에서 정합니다
([그룹](01-getting-started.md#그룹)).

측정 결과 표(자동 갱신, 채널별 값, 저장)는
[측정 결과 표](09-intensity.md#측정-결과-표)를 보세요.

## 팁

- 배경 잡음이 잡히면 **자동 민감도 (k)**를 올리고, 흐린 입자를 놓치면
  낮추세요. **자동 입자 지름**은 실제 입자 크기에 가깝게 두세요.
- 이미지 사이에 똑같은 강도 기준이 필요하면 **수동 threshold**를 쓰세요.
- 응축체 형태를 보고할 때는 등강도선 형태를 켜 두고, 쓴 레벨을 함께 적으세요
  (저장소 README의 Methods 문장 참고).
