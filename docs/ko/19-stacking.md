# 이미지 묶기

채널마다, 초점면(Z)마다, 시점(T)마다 따로 저장된 파일을 한 이미지로 쌓습니다. 원본 파일은
그대로 두고, 이미지 목록에는 묶음 하나로 보입니다. 묶음은 모든 탭 · 내보내기 · 일괄 분석에서 보통
이미지처럼 씁니다.

## 자동으로 묶이는 경우

같은 이름에 `Red` / `Green` / `Blue`만 다른 TIFF 세 개(예: `Control_01_Ch1_Red.tif`,
`..._Ch2_Green.tif`, `..._Ch3_Blue.tif`)를 함께 불러오면 3채널 이미지 하나로 묶습니다. 상태
막대와 작업 기록에 몇 세트를 묶었는지 남습니다.

## 직접 묶기

이미지 목록에서 2개 이상을 고르고 오른쪽 클릭 › **이미지 묶기…**(또는 **파일 › 이미지 묶기…**)를
누릅니다.

| 설정 | 설명 |
|---|---|
| **쌓는 방향** | **채널**(같은 시야를 다른 염색 · 채널로 찍은 파일), **Z**(초점면마다 하나), **시간 (T)**(시점마다 하나). |
| **순서 · 채널** | 행을 끌거나 ▲ ▼로 순서를 바꿉니다. **쓸 채널**: 파일의 어느 채널을 쓸지 (RGB 파일은 이름의 색에 맞는 채널을 자동으로 고름). 채널 방향이면 **채널 이름**과 **색**도 정합니다. |
| **확인** | 크기 · 픽셀 크기가 같은지 보여 줍니다. **크기가 다르면**: 묶지 않고 알림(기본) / 가운데 맞춰 자르기 / 빈 곳을 0으로 채우기. |
| **시점 간격**, **Z 간격** | 시간 · Z 방향일 때만 보입니다. |
| **이름** | 묶음 이름 (기본: 파일 이름의 같은 앞부분). |
| **원본 파일은 묶음 아래에 접어 두기** | 켜면(기본) 원본 이미지 행이 목록에서 빠지고 묶음 아래에 회색으로 접혀 보입니다. |
| **같은 이름 규칙의 나머지 파일도 묶기** | 목록에 같은 규칙의 다른 세트(예: `Control_02_…`)가 있으면 같은 설정으로 함께 묶습니다. |

## 목록에서

묶음 행은 `이름 (3채널)`처럼 보이고, 펼치면 원본 파일이 회색으로 들여 쓰여 보입니다(선택되지 않음,
마우스를 올리면 경로). 휴지통 표시는 묶음 행에만 있습니다. 오른쪽 클릭 › **묶음 풀기**는 원본 파일을
다시 따로 엽니다.

프로젝트에는 묶음의 설정과 원본 파일 경로가 저장되고, 열 때 원본에서 다시 쌓습니다.
