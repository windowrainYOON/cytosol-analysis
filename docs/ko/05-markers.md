# 마커 탭 (scale bar, 타임 스탬프, bleach ROI)

[← 설명서 목차](README.md) · [English](../en/05-markers.md)

여기서 정한 마커는 미리보기에 그려지고, 모든 RGB 저장(TIFF, MP4)과 스택 탭
저장에 들어갑니다. 원본값 스택에는 마커를 넣지 않습니다. 숫자 칸의 **자동**은
이미지 크기에 맞춘 값이며, 숫자를 넣으면 고정됩니다.

## Size marker (scale bar)

묶음 제목의 체크박스로 scale bar를 켜고 끕니다.

| 항목 | 의미 |
|---|---|
| **마커 길이** | µm. **자동**: 파일의 픽셀 크기로 이미지 폭의 약 20 %를 1/2/5/10/20/25/50… µm로 반올림 |
| **위치** | lower right, lower left, upper right, upper left |
| **글자 표시 (예: 10 µm)** | 길이를 글자로 표시 |
| **글자 크기**, **마커 두께** | px |
| **글자-마커 간격**, **가장자리 여백** | px |
| **색** | 막대와 글자 색 |

## Time-series marker (타임 스탬프)

시점이 2개 이상인 이미지에만 그려집니다. 시간은 파일에서 읽습니다(예: CZI
`TimeStamps`).

| 항목 | 의미 |
|---|---|
| **위치** | 기본 upper left |
| **글자 표시** | 시간을 글자로 표시 |
| **단위** | `auto`, `s`, `min`, `h`, `hh:mm:ss`, `mm:ss`, `frame` |
| **소수점 자리** | 0–3 |
| **앞 글자** | 시간 앞에 붙일 글자, 예: `t = ` |
| **시간 보정** | 모든 시간에 더할 초. 예: 처리 시점이 0이 되도록 음수 입력 |
| **글자 크기**, **가장자리 여백**, **색** | scale bar와 같음 |
| **진행 막대 표시** | 시간에 따라 늘어나는 막대. **막대 길이**(이미지 폭의 %, 기본 25), **막대 두께**, **글자-막대 간격** |

## Bleach ROI (파일에 기록된 bleach 영역)

FRAP 등으로 찍은 Zeiss CZI 파일에서, 실제로 bleach한 영역(실행된 bleach
이벤트, 없으면 실험 설정에서 bleach로 지정한 영역)입니다. 영역마다 크기(px,
µm)가 표시됩니다.

| 항목 | 의미 |
|---|---|
| **화면에 표시** | 미리보기에 영역 선을 보이거나 숨김 |
| **저장하는 RGB 이미지(합성·채널별, MP4)에 선 포함** | 내보내는 RGB TIFF / MP4에 선을 그려 넣음(원본값 스택에는 그리지 않음) |
| **영역 이름 표시** | 선마다 이름 표시 |
| **선 두께**, **색** | 선 모양 |

저장할 때마다 영역이 ImageJ ROI `<이름>_bleach_rois.zip`(원은 타원 ROI, 그 밖은
서브픽셀 다각형)으로도 저장되며, 폴더 불러오기가 이 파일을 이미지에 다시
붙입니다. bleach 설정(레이저, 반복 횟수, bleach 뒤 프레임)은
[이미지 정보 탭](10-image-info.md)에 나옵니다.

bleach 영역 기록이 없는 이미지는 **이 이미지에는 bleach 영역 기록이 없습니다**라고
표시됩니다.
