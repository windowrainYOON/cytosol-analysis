# 메뉴, 프로젝트 파일, 작업 기록

[← 설명서 목차](README.md) · [English](../en/13-project-menus.md)

메뉴 막대에는 **파일** 옆에 기능마다 메뉴가 하나씩 있습니다: **LUT**, **마커**,
**Crop**, **세포질 ROI**, **입자 ROI**, **강도 측정**, **Coloc 2**, **라인 프로파일**,
**FRAP 측정**, **스택**, **이미지 정보**, **Figure**. 각 기능 메뉴에는 그 기능의 탭 열기와, 그
기능에 딸린 저장·불러오기가 모여 있습니다. 프로젝트, 자동 인식 불러오기, 일괄
저장은 **파일** 메뉴에 있습니다.

오른쪽 패널에는 처음에 **LUT**(아래쪽에 마커 설정 고정)와 **이미지 정보** 탭만
있고, 기능 메뉴의 **… 탭 열기**를 누르면 그 탭이 옆에 추가됩니다. 다시 누르거나
탭의 ×를 누르면 숨깁니다. 숨겨도 설정과 결과는 그대로 남고, 열려 있던 탭은
프로젝트에 저장됩니다.

## 파일 메뉴

| 항목 | 단축키 | 하는 일 |
|---|---|---|
| **새 프로젝트** | `Ctrl+N` | 모든 이미지를 닫고 새로 시작 (저장하지 않은 변경이 있으면 먼저 묻습니다) |
| **불러오기 (자동 인식)…** | `Ctrl+O` | 아래 [불러오기](#불러오기) |
| **불러오기 (폴더)…** | `Ctrl+Shift+O` | 폴더 안의 이미지·내보낸 파일을 이미지 ID로 짝지어 불러오기 |
| **최근 프로젝트** | | 최근에 열거나 저장한 프로젝트 (열 때 전체 / 설정만을 묻습니다) |
| **프로젝트에서 설정(파이프라인)만 불러오기…** | | 이미지는 그대로 두고 프로젝트·일괄 분석 설정 파일의 탭 설정과 일괄 분석 선택만 ([자세히](15-batch.md#프로젝트에서-설정파이프라인만-불러오기)) |
| **프로젝트 저장** | `Ctrl+S` | 현재 작업 전체를 `.cyproj` 파일로 저장 (처음에는 위치를 묻습니다) |
| **프로젝트 다른 이름으로 저장…** | `Ctrl+Shift+S` | |
| **모든 분석 결과 통합 저장 (이미지별 폴더)…** | `Ctrl+Shift+E` | 이미지마다 폴더 하나에 TIFF, ROI, 측정 CSV를 모두, 그리고 맨 위에 `project.cyproj` |
| **일괄 분석 실행…** / **일괄 분석 결과 보기…** | `Ctrl+B` / `Ctrl+Shift+B` | 그룹·분석을 체크해 한 번에 실행, 이미지별 결과 확인·수정 ([일괄 분석](15-batch.md)) |
| **일괄 분석 결과 저장 (폴더)…** | | 일괄 분석에서 고른 분석의 결과와 설정만 |
| **일괄 분석 설정 저장…** / **불러오기…** | | 분석·그룹 선택과 그 탭들의 설정 (JSON) |
| **이미지별 폴더에 나눠 저장** (체크) | | 폴더에 저장하는 모든 항목: 이미지마다 `<이름>_<이미지 ID>/` 하위 폴더 |
| **측정·프로파일 저장 시 ROI와 ROI가 그려진 이미지(.png)도 함께** (체크) | | 측정 CSV·라인 프로파일 옆에 `<이름>_RoiSet.zip`, `<이름>_particles.zip`, `<이름>_line.roi`, `<이름>_image.png` |
| **작업 기록 보기…** | `Ctrl+Shift+L` | 아래 [작업 기록](#작업-기록) 창 |
| **작업 기록 저장 (CSV)…** | | 작업 기록 전체 |
| **설정…** (macOS에서는 앱 메뉴, `⌘,`) | | 마우스 민감도 (아래 [설정](#설정)) |
| **종료** | `⌘Q` (macOS) | 저장하지 않은 변경이 있으면 먼저 묻습니다 |

## 기능별 메뉴

| 메뉴 | 항목 |
|---|---|
| **LUT** | **이미지 내보내기 (TIFF / MP4)…**(`Ctrl+E`): 저장 옵션 창(현재 이미지만 / 모든 이미지, 범위, 합성·채널별 RGB, 원본값 스택, 타임시리즈 형식) 뒤에 폴더([자세히](02-lut-export.md#이미지-내보내기-tiff--mp4)). **LUT 프리셋 저장…** / **LUT 프리셋 불러오기…** (JSON, 불러오면 모든 이미지에 적용) |
| **마커** | **마커 설정 저장…** / **마커 설정 불러오기…** (scale bar, 타임 스탬프, bleach ROI 표시 설정, JSON) |
| **Crop** | **Crop 탭 열기**, **Crop 영역 ROI 저장** (현재 이미지 / 모든 이미지, `<이름>_crops.zip`), **Crop 영역 ROI 불러오기…** |
| **세포질 ROI** | **세포질 ROI 탭 열기**, 저장할 ROI(세포 전체·핵·세포질) 체크, **ROI 저장** (현재 이미지 / 모든 이미지), **ROI 불러오기…**, 측정 CSV(현재 이미지 / 모든 이미지 측정 + 저장) |
| **입자 ROI** | **입자 ROI 탭 열기**, **입자 ROI 저장 (현재 이미지)…**, **입자 ROI 불러오기…**, 측정 CSV |
| **강도 측정** | **강도 측정 탭 열기**, 측정 CSV(현재 / 모든 이미지) |
| **Coloc 2** | **Coloc 2 탭 열기**, CSV(현재 이미지), 모든 이미지 CSV(폴더), 그래프, PDF 리포트 |
| **라인 프로파일** | **라인 프로파일 탭 열기**, CSV, 그래프(PNG / PDF / SVG / TIFF), **선 ROI 불러오기…** |
| **FRAP 측정** | **FRAP 측정 탭 열기**, **요약 저장: 모든 이미지·그룹 CSV + 그래프 (폴더)…**, CSV, 그래프, **FRAP ROI 저장 / 불러오기…** ([FRAP 측정 탭](14-frap.md)) |
| **스택** | **스택 탭 열기**, 현재 투영 / 3D 회전 시리즈 저장: 저장 옵션 창(원본 해상도, 모든 시점, fps, 회전 범위) 뒤에 파일 이름 |
| **이미지 정보** | CSV, 원본 메타데이터 저장 (탭은 항상 열려 있음) |
| **Figure** | **Figure 창 열기…**(`Ctrl+Shift+F`). Figure 저장과 inset ROI 저장은 [Figure 창](11-figure.md) 안에 있습니다. |

기능 메뉴의 불러오기는 파일을 고르는 창에서 그 종류의 파일을 먼저 보여 줍니다.
고른 파일은 내용으로 종류를 다시 확인하므로, 다른 종류의 파일을 골라도 맞는 곳에
들어갑니다.

## 불러오기

**불러오기 (자동 인식)…**은 고른 파일이 무엇인지 알아서 처리합니다(여러 개를 한 번에
골라도 됩니다).

| 고른 파일 | 하는 일 |
|---|---|
| `.cyproj` | 프로젝트 열기 (지금 작업은 닫힘, 저장하지 않은 변경이 있으면 먼저 물음) |
| 이미지 (`.tcf`, `.czi`, `.oir`, `.tif`) | 목록에 추가. 이미 목록에 있는 파일은 다시 열지 않습니다. 이 프로그램이 내보낸 TIFF는 원본이 열려 있으면 그 원본에 연결만 합니다. |
| 세포 ROI (`<이름>_RoiSet.zip`, `.roi`) | 이미지 ID(없으면 파일 이름)가 맞는 이미지에, 맞는 이미지가 없으면 지금 보고 있는 이미지에 불러옵니다. 이미 ROI가 있으면 바꿀지 한 번 묻습니다. |
| 입자 ROI (`<이름>_particles.zip`) | 입자 ROI로 (설정이 들어 있으면 설정째로) |
| Crop (`<이름>_crops.zip`) | Crop 영역으로 |
| 라인 (`<이름>_line.roi`) | 라인 프로파일 선으로 |
| FRAP ROI (`<이름>_frap_rois.zip`) | FRAP 측정 탭의 Bleach / Control / Background ROI로 |
| bleach ROI (`<이름>_bleach_rois.zip`) | bleach 영역으로 |
| LUT 프리셋 (`.json`) | 모든 이미지에 적용 |
| 마커 설정 (`.json`) | 마커 설정에 적용 |
| `image_groups.csv` | 그룹 복원 |

**불러오기 (폴더)…**는 폴더와 하위 폴더를 뒤져 같은 규칙으로 짝짓습니다. 이미
열려 있는 이미지에는 그 이미지의 ROI·Crop·라인을 붙이고, 열려 있지 않은 원본은
엽니다(원본이 없으면 내보낸 TIFF 중 raw 스택 우선). 자세한 짝짓기 규칙은
[저장되는 파일](12-output-files.md#결과-다시-불러오기)을 보세요. 파일과 폴더는
창에 끌어다 놓아도 됩니다.

## 프로젝트 파일 (`.cyproj`)

프로젝트 파일 하나에 작업 전체가 들어갑니다. 프로젝트만 열면 이어서 고치고
분석할 수 있습니다.

- 이미지 목록과 각 이미지를 읽은 방법(TCF HT/FL 정렬 여부), 이미지 ID
- 이미지마다 LUT, Crop 영역, 그룹, 보고 있던 Z·시점, 라인 프로파일 선, 세포질
  ROI 채널 역할, 입자 설정
- 세포·핵 ROI (픽셀 그대로, 검출에 쓴 포화값·threshold 포함), 파일에서 불러온 입자
  ROI, 불러온 bleach ROI, Coloc 2 결과
- 모든 탭의 설정(검출 파라미터, 측정값 선택, 논리식, 마커, 내보내기 옵션 …)과
  열려 있던 탭
- 측정 결과 표의 일괄 측정 결과(모든 이미지 측정)
- Figure 창의 표(칸마다 이미지·영역·채널, inset, 레이아웃)
- 일괄 분석의 분석·그룹 선택과 결과 표
- 작업 기록

프로젝트를 열 때 **전체 (이미지 + 분석 값)**와 **설정(파이프라인)만** 중에서 고릅니다
([일괄 분석](15-batch.md#프로젝트에서-설정파이프라인만-불러오기)).

이미지 파일 자체는 복사하지 않고 위치만 저장합니다: 프로젝트 파일을 기준으로 한
상대 경로와 절대 경로를 함께 적어 두므로, 프로젝트와 이미지를 같이 옮기거나
다른 컴퓨터로 복사해도 찾습니다. 그래도 못 찾은 이미지가 있으면 이름을 보여 주고
폴더를 고르라고 합니다. 그 폴더(하위 폴더 포함)에서 같은 이름의 파일을 찾고,
그래도 없는 이미지는 빼고 엽니다. 이미지 ID가 저장할 때와 다르면 다른 파일일 수
있다고 알려 줍니다.

창 제목 끝의 `*`는 저장하지 않은 변경이 있다는 뜻입니다.

## 작업 기록

검출, ROI 수정, 측정, 불러오기, 저장, 그룹 지정처럼 상태 표시줄에 나오는 작업이
시간, 이미지, 이미지 ID와 함께 쌓입니다. **파일 › 작업 기록 보기…**에서 보고, **파일 ›
작업 기록 저장 (CSV)…**로 저장합니다. 프로젝트에 함께 저장되므로 프로젝트를
다시 열면 이전 기록 뒤에 이어서 쌓입니다.

## 설정

**파일 › 설정…**에서 마우스 민감도를 정합니다(1.0 = 기본 빠르기, 0.1–3.0배).
설정은 컴퓨터에 기억됩니다.

| 항목 | 기본 | 뜻 |
|---|---|---|
| **확대/축소 드래그 (Cmd/Ctrl + 드래그)** | 0.6 | 위로 드래그하면 확대, 아래로 축소. 작을수록 천천히 |
| **T · Z 이동 (오른쪽 버튼 드래그)** | 1.0 | 오른쪽 버튼 드래그로 시점·Z를 옮기는 빠르기 |
| **휠 시간 이동 (타임시리즈)** | 1.0 | 휠 한 칸에 옮기는 시점 수 |
