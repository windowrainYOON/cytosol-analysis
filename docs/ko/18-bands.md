# 등거리 띠 탭 (핵 → 세포막 등거리 띠)

**Tool › 등거리 띠 › 등거리 띠 탭 열기**(또는 View 메뉴)로 여는 탭입니다. v0.57 – 0.59에는 세포질 ROI 탭
맨 아래, 그 전에는 강도 측정 탭에 있었습니다. 그때 저장한 프로젝트의 띠 설정도 그대로 불러옵니다.
먼저 [세포질 ROI 탭](03-cytosol-roi.md)에서 세포와 핵 ROI를 잡아야 합니다.

세포질을 핵에서의 거리가 같은 띠(등거리선 사이)로 나누고 띠마다 채널별 강도를 잽니다.
핵이 있는 세포만 잽니다.

| 설정 | 설명 |
|---|---|
| **거리** | **상대 거리**(기본): 핵에서의 거리 ÷ (핵에서의 거리 + 세포 경계까지의 거리). 세포 크기와 상관없이 0 = 핵 경계, 1 = 세포 경계. **핵 경계에서의 거리 (µm)**: 핵 윤곽에서 잰 실제 거리(보정 정보가 없으면 픽셀). 프레임에서 잘린 세포는 잘린 경계를 세포 경계로 봅니다. |
| **범위** | 잴 거리 범위. 상대 거리는 기본 0 – 1, µm는 0 – 10. |
| **띠 개수** | 범위를 같은 폭으로 나눌 개수 (기본 10). |
| **이미지에 띠 표시** | 켜면 이 탭에서 띠의 경계를 청록색으로 그립니다. |

아래 측정 표(측정값 선택, 현재 이미지 / 모든 이미지, 자동 갱신)는 세포질 ROI 탭의 세포 강도 측정 표와
같은 방식입니다. 행은 세포와 띠마다 하나이고 열은 `band`, `distance_rel`(또는
`distance_µm`, 띠 가운데 값)과 `_from`, `_to`, 면적, 채널별 측정값입니다. 입자를 정했으면
띠마다 `n_particles`(중심이 그 띠에 있는 입자 수), `particle_area_um2`,
`particle_area_fraction`, 채널별 `_particle_Mean`(띠 안 입자 픽셀의 평균)도 들어갑니다.

**그래프**: x, y에 측정한 열 중 아무거나 고를 수 있습니다(기본 x = 거리, y = 첫 채널의
Mean). 회색 선은 세포마다, 빨간 선과 띠는 띠별 세포 평균 ± SD입니다. 표 보기를 **모든
이미지**로 바꾸면 일괄 측정 결과를 그립니다.

저장: **파일 › 내보내기…**의 **등거리 띠** 항목에서 **띠별 측정 CSV**(이미지별 `<이름>_bands.csv`와
전체 `bands.csv`)와 **띠 그래프 (현재 이미지)**를 고릅니다 ([내보내기 창](17-export.md)). 그래프는
**그래프 › 등거리 띠**로 그래프 편집 창에서도 열 수 있습니다. 일괄 분석에서는 **핵 → 세포막 등거리 띠**
단계가 이 탭의 설정을 씁니다.
