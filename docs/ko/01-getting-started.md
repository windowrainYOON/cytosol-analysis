# 시작하기: 이미지 열기·보기·그룹

[← 설명서 목차](README.md) · [English](../en/01-getting-started.md)

## 열 수 있는 파일

| 형식 | 읽는 내용 |
|---|---|
| Tomocube `.TCF` | HT(굴절률)와 FL(형광) 볼륨, 타임시리즈, 저장된 2D MIP |
| Zeiss `.czi` | 모든 채널, Z, T, scene, 표시 색, 프레임 시간, bleach 영역(FRAP) |
| Olympus/Evident `.oir` | 채널, Z, T, FluoView LUT 색 |
| `.tif` / `.tiff` | ImageJ hyperstack과 OME-TIFF (T/Z/C, 픽셀 크기, 채널 이름·색). 일반 다중 페이지 TIFF는 Z 스택, RGB TIFF는 R/G/B 채널로 엽니다 |

픽셀 크기, Z 간격, 채널 이름·색, 채널마다 담을 수 있는 값의 범위(예: 12-bit는
0–4095)는 파일의 메타데이터에서 읽습니다.

## 이미지 추가

- 이미지 목록 아래 **파일 추가…**, **파일 › 파일 열기…**(`Ctrl+O`), 또는
  파일을 창에 끌어다 놓습니다.
- **폴더 불러오기…**(`Ctrl+Shift+O`) 또는 폴더 끌어다 놓기: 폴더와 하위
  폴더를 뒤져 원본 이미지, 내보낸 TIFF, ROI 파일(`.zip` / `.roi`)을 이미지
  ID로 짝지어 엽니다(아래 참고). 원본이 없으면 내보낸 파일 중 가장 알맞은
  것(raw 스택 우선)을 대신 열고, ROI는 해당 이미지에 자동으로 붙입니다.
  `image_groups.csv`가 있으면 그룹도 복원합니다.
- 목록의 이미지에 마우스를 올리면 이미지 ID, 원본 파일, 그룹, 함께 찾은
  내보낸 파일, 세포 ROI 수가 보입니다.

### TCF: HT와 FL을 한 이미지로

**TCF: HT와 FL을 정렬해 한 이미지로**(기본 켜짐)는 TCF를 채널 `RI`, `CH0`,
`CH1`, … 을 가진 이미지 하나로 엽니다. 형광을 HT 픽셀 격자에 맞춰
리샘플링하고(공통 영상 중심 기준 픽셀 크기 + 최대 2 µm 자동 미세 정렬), Z는
`3DFL/OffsetZ`로 맞춥니다. 끄면 HT와 FL이 따로 열립니다. 새로 추가하는
파일부터 적용됩니다.

## 이미지 목록

- `Shift`/`Ctrl`(`⌘`) + 클릭으로 여러 개를 선택합니다.
- **목록에서 제거** 또는 `Delete`: 선택한 이미지를 목록에서 뺍니다(파일은
  지우지 않습니다).

### 그룹

그룹은 측정 결과의 `group` 열과 그룹별 요약에 쓰입니다.

- **그룹 지정…**: 선택한 이미지를 한 그룹으로 묶습니다. 제안되는 이름은
  파일 이름에서 끝 번호를 뺀 공통 부분입니다(`abc`, `abc_0001`, `abc_0002`
  → `abc`). 고쳐 쓰거나 이미 있는 그룹을 고를 수 있습니다.
- **자동 그룹**: 이름이 끝 번호만 다른 이미지끼리 묶습니다. 2개 이상
  선택했으면 선택한 이미지만, 아니면 모든 이미지가 대상입니다. 만들 그룹을
  먼저 보여 주고 확인을 받습니다.
- **그룹 이름 변경…**, **그룹 해제**.
- 그룹은 목록에서 폴더처럼 펼치거나 접을 수 있고, 폴더를 누르면 안의
  이미지가 모두 선택됩니다. 측정값이나 내보내기를 저장하면
  `image_groups.csv`가 함께 저장되고, 폴더 불러오기가 이를 다시 읽습니다.

## 보기

### Z (슬라이스)

- 이미지 왼쪽의 세로 슬라이더: 아래쪽이 첫 슬라이스이고, 슬라이스 번호와
  높이(µm)가 표시됩니다. 슬라이더 위에서 휠, `↑` `↓`, `PageUp` `PageDown`으로도
  움직입니다.
- **MIP**: 모든 슬라이스의 최대값 투영. 슬라이더를 움직이면 다시 슬라이스
  보기로 바뀝니다.
- TCF는 필요한 만큼만 읽습니다. 슬라이스 하나는 그 HT 평면과 주변 FL 몇
  장만 읽으므로 Z를 넘겨 보는 것이 빠르고 메모리도 적게 씁니다.

### T (타임시리즈)

- T 축이 있는 파일(TCF, CZI, OIR)은 이미지 아래에 **T** 슬라이더가
  생깁니다. 드래그하는 동안 이미지가 따라오고, 히스토그램과 라인 프로파일은
  손을 뗄 때 갱신됩니다.
- Z 스택이 있으면 현재 Z(또는 MIP)의 모든 시점을 백그라운드에서 미리
  읽어 두므로(최대 1.5 GB, 상태 표시줄에 진행 상황) 넘겨 볼 때 다시 그리기만
  합니다.
- **이미지 위에서 오른쪽 버튼 드래그**: 좌우로 T, 위아래로 Z를 동시에
  움직입니다.

### 확대와 이동

- 마우스 휠: 확대·축소.
- **영역 확대**: 누른 뒤 사각형을 드래그합니다. 버튼 없이 `Shift`+드래그도
  됩니다.
- **화면 맞춤**: 이미지 전체 보기로 돌아갑니다.
- 가운데 버튼 드래그로 이동합니다(Z·T가 없는 이미지는 오른쪽 버튼도).

### 채널

채널을 켜고 끄는 **채널 표시** 체크박스와 색·대비는
[LUT · 내보내기 탭](02-lut-export.md)에 있습니다.

## Crop 영역

Crop은 따로 보고, 투영하고, 저장할 수 있는 사각형 영역입니다.

1. **Crop 추가 (드래그)**를 누르고 이미지 위에서 드래그합니다.
   `Shift`+드래그는 정사각형입니다. 반복하면 영역이 더 생기고, 이미지에
   번호가 붙으며 **Crop 영역 (각각 따로 저장)** 목록에 나옵니다.
2. 이미 있는 Crop 안을 드래그하면 위치를 옮깁니다.
3. **선택한 Crop만 보기**: 한 영역만 미리 봅니다.
4. **선택 삭제** / **전체 삭제**.
5. **같은 크기 이미지에 복사**: 이 이미지의 Crop을 크기가 같은 다른 모든
   이미지에 복사합니다. 복사한 뒤 이미지마다 드래그로 위치를 옮기면 됩니다.

## 이미지 ID

이미지마다 `A9F3-2596-73B6` 같은 ID가 붙습니다. 현미경이 파일에 기록한
정보(TCF `UniqueID`, CZI 파일 GUID, OIR 획득 시각과 채널 UUID, OME-TIFF
`UUID`, 그 밖에는 파일 내용의 해시)로 만들기 때문에 파일 이름을 바꾸거나
복사해도 유지됩니다. 미리보기 아래와 목록 툴팁에 표시됩니다.

내보내는 모든 파일에 ID가 들어갑니다. TIFF는 ImageJ `Info`/`Properties`
(`CytosolImageID`, `CytosolSource`; Fiji에서 Image › Show Info), RoiSet은 각
ROI의 속성, CSV는 `image_id` 열입니다. **폴더 불러오기…**가 파일을 짝짓는
기준이고, **ROI 불러오기…**가 다른 이미지에서 저장한 ROI를 열 때 묻는
이유이기도 합니다.
