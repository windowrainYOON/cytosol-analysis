# 일괄 분석 (그룹별 분석 파이프라인)

[← 설명서 목차](README.md) · [English](../en/15-batch.md)

이미지를 모두 불러와 그룹으로 묶은 다음, 어떤 분석을 할지 체크박스로 고르면
고른 그룹의 모든 이미지에 그 분석을 차례로 자동 실행합니다. 결과를 이미지별로
보고, 이상한 이미지만 열어 ROI나 설정을 고친 뒤 다시 측정하고, 일괄 분석 결과와
설정만 따로 저장할 수 있습니다. 모두 **파일** 메뉴에 있습니다.

## 순서

1. **불러오기**로 이미지를 모두 엽니다.
2. 왼쪽 목록에서 **그룹 지정…**(또는 **자동 그룹**)으로 이미지를 묶습니다.
   그룹이 없으면 모든 이미지가 ‘(그룹 없음)’ 하나로 취급됩니다.
3. 필요한 탭에서 세부 설정을 맞춥니다 (예: 세포질 ROI 탭의 자동 / 수동 threshold,
   입자 ROI 탭의 채널, Coloc 2 탭의 두 채널). 일괄 분석은 각 탭의 **현재 설정**을 씁니다.
4. **파일 › 일괄 분석 실행…**(`Ctrl+B`)을 누릅니다.
   - **이미지 그룹**: 분석할 그룹을 체크합니다 (그룹마다 이미지 수 표시).
   - **수행할 분석**: 세포질 ROI 검출, 입자 ROI 검출, 세포질 ROI 강도 측정, 입자 측정,
     강도 측정 (논리 영역), 핵 → 세포막 등거리 띠, Coloc 2, FRAP 측정 중에서 체크합니다.
     항목에 마우스를 올리면 어느 탭의 설정을 쓰는지 보입니다.
   - **ROI가 이미 있는 이미지도 다시 검출**: 끄면(기본) ROI·입자 설정이 이미 있는 이미지는
     그대로 두고 없는 이미지만 검출합니다. 손으로 고친 ROI를 지키려면 꺼 두세요.
   - **선택한 분석의 설정 탭 열기**: 체크한 분석의 탭을 오른쪽에 열어 실행 전에 설정을 확인합니다.
   - **실행**: 검출 → 측정 순서로 실행합니다. 세포질 ROI의 크기 범위가 **자동**이면
     이미지마다 자기 범위를 씁니다.
5. 끝나면 **일괄 분석 결과** 창이 열립니다.

## 결과 확인과 수정

**일괄 분석 결과** 창(**파일 › 일괄 분석 결과 보기…**, `Ctrl+Shift+B`)에는 이미지마다
한 줄로 그룹, 이미지, 그리고 분석마다 세포 ROI 수, 입자 수, 측정 행 수, Coloc 2 ROI 수,
FRAP mobile fraction·t½가 나옵니다. 값이 없거나 0인 칸은 빨간색입니다. 위쪽에는 실행
시각, 그룹, 분석과 문제(채널이 없는 이미지 등)가 나옵니다.

- 행을 두 번 누르면 그 이미지를 열고, 누른 열의 분석 탭으로 갑니다. 거기서 ROI를
  고치거나(합치기, 자르기, 삭제 …) 설정을 바꿉니다.
- **다시 측정 (수정 반영)**: 검출은 다시 하지 않고, 고친 ROI 그대로 고른 분석의 측정만
  다시 합니다. 입자는 설정이 바뀌었거나 세포 ROI가 바뀐 이미지만 다시 찾습니다.
- **전체 다시 실행…**: 그룹·분석을 다시 골라 처음부터 실행합니다.
- 측정 결과는 각 측정 탭의 결과 표 **모든 이미지 (일괄 측정 결과)**에도 들어갑니다.

## 저장과 불러오기

| 항목 | 하는 일 |
|---|---|
| **파일 › 일괄 분석 결과 저장 (폴더)…** | 일괄 분석에서 고른 분석의 결과만, 그 이미지들만 저장합니다. 저장할 때 다시 측정하므로 고친 내용이 들어갑니다. 이미지마다 `<이름>_<이미지 ID>/` 폴더(ROI, 입자 ROI, 측정 CSV, Coloc 2 CSV, FRAP 곡선)와 맨 위에 전체 CSV·요약, `image_groups.csv`, `batch_summary.csv`(결과 창의 표), `batch_settings.json`(분석·그룹·탭 설정, 실행 시각) |
| **파일 › 일괄 분석 설정 저장…** | 고른 분석과 그룹, 그 분석들이 쓰는 탭의 설정을 JSON(`format: cytosol-viewer-batch`)으로 저장합니다. 다른 이미지셋에 같은 파이프라인을 다시 쓸 때 씁니다 |
| **파일 › 일괄 분석 설정 불러오기…** | 위 파일(또는 `batch_settings.json`)을 불러와 탭 설정과 분석 선택을 되돌립니다. **불러오기 (자동 인식)**도 이 파일을 알아봅니다 |

프로젝트(`.cyproj`)에도 일괄 분석의 분석·그룹 선택과 결과 표가 저장됩니다.

## 프로젝트에서 설정(파이프라인)만 불러오기

프로젝트를 열 때(**불러오기**, **최근 프로젝트**) 무엇을 불러올지 묻습니다.

- **전체 (이미지 + 분석 값)**: 지금 작업을 닫고 이미지, ROI, 분석 값과 설정을 모두 엽니다.
- **설정(파이프라인)만**: 이미지와 분석 값은 그대로 두고, 프로젝트의 탭 설정, 열려 있던
  탭, 측정할 채널, 일괄 분석 선택만 가져옵니다. 새 이미지셋에 예전 분석 설정을 그대로
  쓸 때 편합니다.

**파일 › 프로젝트에서 설정(파이프라인)만 불러오기…**는 묻지 않고 바로 설정만 가져옵니다
(프로젝트나 일괄 분석 설정 파일 모두 됩니다).
