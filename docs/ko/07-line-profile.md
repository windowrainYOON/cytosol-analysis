# 라인 프로파일 탭 (선 강도 프로파일)

[← 설명서 목차](README.md) · [English](../en/07-line-profile.md)

ImageJ의 RGB Profiler(채널마다 Plot Profile)처럼, 선을 따라 채널별 원본 강도를
채널 색으로, 거리(µm)에 대해 그립니다.

## 선 그리기

1. 이미지 위의 **라인 프로파일 (선 그리기)** 또는 탭의 **선 그리기 (드래그)**를
   누릅니다.
2. 이미지 위에서 선을 드래그합니다. `Shift`를 누르면 수평·수직·45°.
3. **선 지우기**로 지웁니다.

값은 현재 Z(또는 MIP)와 시점의 것이며, Z·T·LUT 색을 바꾸면 그래프도 따라
바뀝니다. 탭에 선의 길이, 두께, 평면, 양 끝 좌표(px)가 표시됩니다.

## 설정

| 항목 | 의미 |
|---|---|
| **선 두께** (px) | 1 = 선 위의 값. 2 이상이면 선에 수직으로 그만큼의 픽셀을 평균(ImageJ 선 두께와 같음) |
| **LUT에서 숨긴 채널 제외** | LUT 탭에서 숨긴 채널은 빼기 |
| **채널별 0–1 정규화** | 채널마다 0–1로 맞춰 모양을 비교 |

## 저장

- **CSV 저장…**: 거리 + 채널마다 한 열.
- **그래프 저장…**: PNG/TIFF(300 dpi), PDF, SVG.
- **저장할 때 선 ROI(.roi)와 선이 그려진 이미지(.png)도 함께 저장**: 같은 폴더에
  `<이름>_line.roi`(선 두께가 들어간 ImageJ 직선 ROI)와 `<이름>_image.png`(현재
  LUT 이미지 위에 선)를 저장합니다.

## ImageJ와의 일치

샘플링은 ImageJ와 같습니다: 쌍선형 보간, round(길이) + 1개 점, 두께 > 1은
ImageJ가 선을 펴는(straighten) 방식으로 평균. 두께 1은 값이 똑같고, 더 두꺼운
선은 상대 오차 4 × 10⁻⁵ 이내입니다.
