# Cytosol Viewer 사용 설명서 (한국어)

[English manual](../en/README.md)

Cytosol Viewer(v0.38)는 Tomocube TCF, Zeiss CZI, Olympus/Evident OIR, TIFF
이미지를 열어 세포·핵·세포질 ROI를 찾고, ImageJ/Fiji와 같은 방식으로 측정한
뒤 이미지, ROI, 표, figure로 내보내는 프로그램입니다.

설명서에 나오는 **굵은 글씨**는 화면에 보이는 버튼·항목 이름 그대로입니다.

## 창 구성

- **왼쪽 패널**: 이미지 목록과 그룹
- **가운데**: 이미지. 왼쪽에 Z 슬라이더, 아래에 T 슬라이더, 위에 보기 버튼
- **오른쪽 패널**: 처음에는 **LUT**, **마커**, **이미지 정보** 탭만 있고(위쪽 캡슐 버튼으로 전환), 나머지 기능 탭은 **View** 메뉴(또는 각 기능 메뉴의 **… 탭 열기**)로 열고 닫습니다
- **메뉴 막대**: **파일**(프로젝트, 자동 인식 불러오기, 통합 저장, 작업 기록, 설정)
  옆의 **Tool** 메뉴 안에 기능마다 하위 메뉴(**LUT**, **마커**, **Crop**, **세포질 ROI**, **입자 ROI**,
  **강도 측정**, **Coloc 2**, **라인 프로파일**, **FRAP 측정**, **스택**, **이미지 정보**, **Figure**)가
  있고, 각 메뉴에 그 기능의 탭 열기와 저장·불러오기가 있습니다.
  [메뉴, 프로젝트 파일, 작업 기록](13-project-menus.md)

## 화면 디자인 (Apple HIG)

화면은 Apple Human Interface Guidelines의 데스크탑 규칙을 따릅니다.

- 모든 플랫폼에서 같은 디자인 시스템 스타일로 그려집니다(밝게·어둡게, 시스템 설정을 따름).
  색은 모두 디자인 토큰(강조 파랑, 보조 글자색, 구분선, 채움색)에서 옵니다.
- macOS(tahoe) 스타일: 버튼·탭 버튼·칩은 캡슐 모양, 입력칸은 테두리 없는 채움(반경 8),
  모서리 반경은 카드(12) → 선택 줄(10) → 값(6)처럼 안쪽으로 갈수록 작아집니다. 창은 이미지 목록 · 미리보기 · 도구 세 영역으로 바탕색과 구분선으로 나뉘고, 영역마다 안쪽 여백(16–20 px)이 있습니다. 각 탭의
  주요 실행 버튼(예: **ROI 검출 (현재 이미지)**, **지금 측정**)만 파란 채움 버튼입니다.
- 선택 컨트롤은 쓰임에 따라 나뉩니다: **스위치**는 값의 **자동 / 수동** 선택에만,
  켜고 끄는 옵션 하나는 **체크박스**, 여러 값을 함께 고르는 짧은 항목(측정값 Mean·StdDev…,
  측정할 채널, 채널 표시, ROI 종류)은 **다중 선택 칩**(켜면 체크 표시와 파란 테두리),
  하나만 고르는 항목은 **라디오 버튼**, 패널 안의 하위 탭(예: 자동 / 수동 (threshold))은
  **선택 칩**입니다.
- 설정은 둥근 반투명 카드(인셋 그룹) 안에 모입니다. 모든 탭이 같은 여백을 써서 그룹 제목,
  카드 안의 항목, 카드 밖의 설명 글이 같은 세로줄(카드 안쪽 12 px)에서 시작합니다.
- 메뉴와 목록의 선택 항목은 파란 알약 + 흰 글자입니다.
- macOS에서는 왼쪽 이미지 목록과 오른쪽 탭 창이 반투명 사이드바 재질(Liquid Glass)로
  뒤 화면이 비쳐 보이고, 가운데 이미지 미리보기는 불투명하게 남습니다. 손쉬운 사용의
  **투명도 줄이기**가 켜져 있으면 불투명하게 그려집니다.
- 설명·도움말 글자는 한 단계 작은 보조 글자색으로, 경고는 색 점 + 글자
  (예: 회색 배경의 주황 점과 문구)로 보여 줍니다. 색만으로 상태를 나타내지 않습니다.
- 되돌릴 수 없는 삭제·제거 버튼은 다른 버튼과 떨어진 곳에 빨간 글자로 있고, 이름 끝의
  `…`는 확인 창이 뜬다는 뜻입니다. 확인 창의 기본 버튼(Return)은 **취소**입니다.
  되돌리기가 있는 세포 ROI 삭제는 확인 없이 바로 지웁니다.
- 측정 그래프(FRAP, 라인 프로파일, 그래프 편집 창, Figure)와 이미지 미리보기는 이 스타일과
  무관하게 지금과 같은 모양입니다.
