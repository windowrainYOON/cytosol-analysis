# 3D 투영 · 단면 보기 (캔버스 아이콘)

[← 설명서 목차](README.md) · [English](../en/06-stack.md)

**v0.73부터** 스택 탭은 없고, 캔버스 오른쪽 위의 보기 아이콘 세 개
**[라인 프로파일 · 자 · 단면 · 3D 투영]** 중 하나로 봅니다. 한 번에 하나만 켜지고, 같은 아이콘을 다시
누르면 보통 XY 보기로 돌아옵니다. 설정은 **Preferences › 3D 스택 보기**와 **단면 보기**에 있고,
저장은 **파일 › 내보내기…**의 **3D 스택** 항목입니다.

## 3D 투영 보기

- 캔버스 전체가 3D 보기가 됩니다. GPU(OpenGL)로 그려서 돌릴 때 바로 바뀝니다. GPU를 쓸 수 없으면
  CPU 투영으로 그리고 상태 칩에 그렇게 표시합니다.
- **드래그**로 3축 자유 회전(트랙볼), 각도 칩과 **↺**(처음 각도)가 캔버스 위에 있습니다.
- 볼륨은 미리 준비합니다(준비 칩). 시계열은 모든 시점의 볼륨을 한 번에 준비하므로 T를 움직여도 바로
  보입니다(지금 시점부터 양옆으로). RAM 한도를 넘으면 디스크 캐시(`.cycache`)에 둡니다.

**Preferences › 3D 스택 보기**

| 항목 | 뜻 |
|---|---|
| **렌더 방식** | MIP: 광선 위의 가장 밝은 값 · 반투명: 방출-흡수 · 표면: 기준 밝기를 처음 넘는 곳 |
| **회전** | **3축 자유 (트랙볼)** 또는 **한 축 (Y)** |
| **Z 간격** | **자동** = 파일 메타데이터의 Z 간격, 끄면 µm로 직접 입력 |
| **렌더 해상도** | 준비하는 볼륨의 XY 해상도 (**1/2 (기본)**, **원본** …). 낮추면 메모리와 준비 시간이 줄어듭니다 |
| **고화질 렌더 시점** | **3D를 켤 때** 또는 **이미지를 고를 때 (미리)** |
| **메모리 한도** | 미리 준비한 볼륨을 RAM에 둘 한도 |
| **LUT 연동** | LUT 탭의 Min / Max / 색을 그대로 씁니다 |

사이드바에서 **Crop 행을 클릭**하면(Crop 보기, v0.75) 3D 투영과 단면 보기가 그 Crop 영역만 보여 줍니다. 이미지 행을 클릭하면 전체로 돌아갑니다.

## 단면 보기

Fiji Orthogonal Views처럼 지금 Z의 XY 평면 아래에 X 단면(XZ), 오른쪽에 Y 단면(YZ)을 같은
배율로 보여 줍니다. XY에서 클릭하거나 점을 끌면 자르는 자리가 바뀌고(흰 선), 단면을 클릭하면 Z가
그 자리로 옮겨집니다(단면 위 노란 점선). **Preferences › 단면 보기**: **단면 배치**, **자른 선 표시**,
**Z 간격은 3D 스택 보기와 같게**.

- **MIP** 체크박스(위 줄, v0.74): 켜면 XY 패널이 Z 최대 투영(MIP)이 되고, 오른쪽 Y 단면 · 아래 X 단면은
  그대로 클릭한 점의 단면입니다(노란 Z 점선은 숨김). 메인 보기에서 MIP를 켠 채 단면 보기로 오면 켜진 채로 열립니다.
- **스케일 바**(v0.74): XY, Y 단면, X 단면 패널마다 왼쪽 아래에 흰 막대와 길이(예: 2 µm)를 그립니다.
  길이는 패널 폭의 1/3을 넘지 않는 가장 큰 깔끔한 값으로 자동으로 고릅니다. 세 패널은 배율이 같아 막대의
  µm도 같은 뜻입니다(Z 방향 크기는 Z 간격으로 맞춤).

## 저장 (파일 › 내보내기 › 3D 스택)

- **3D 투영 이미지 (지금 각도, PNG)**: 3D 투영 보기의 지금 각도와 렌더 방식으로 저장.
- **3D 회전 시리즈 (Y축 한 바퀴)**, **MP4 동영상으로 (끄면 TIFF)**.

---

아래는 v0.72까지의 스택 탭 설명입니다(2D 투영 방법의 뜻은 같습니다).

## 투영 종류

- **2D projection (스택을 한 장으로)**: Z 범위를 한 장으로 합칩니다.
- **3D projection (돌려 보기)**: 볼륨을 각도만큼 돌려서 투영합니다.

## 범위

- **Z 슬라이스**: 첫–마지막 슬라이스. **전체**는 모든 슬라이스.
- **선택한 Crop 영역만 (빠름)**: 사이드바에서 이미지 아래의 Crop 항목으로 고른 영역만 투영합니다.

## 2D projection

**방법**: Max intensity, Average intensity, Sum slices, Min intensity, Standard
deviation, Median (ImageJ Z Project와 같은 종류).

## 3D projection

| 항목 | 의미 |
|---|---|
| **방법** | 시선 방향으로 Brightest point (max) 또는 Mean value |
| **회전축** | **Y축 (좌우로 돌리기)** 또는 **X축 (위아래로 기울이기)** |
| **각도** | −180°–180°, 슬라이더나 숫자 |
| **Z 간격** | **자동** 스위치: 켜면 메타데이터의 voxel Z / 픽셀 크기(칸과 아래에 계산값 표시), 끄면 칸에 직접 입력(µm). 파일에 Z 간격이 없으면 자동은 픽셀 1개 간격이므로 실제 간격을 직접 넣으세요. |
| **미리보기** | 미리보기 해상도: **빠름 (~256 px)**, **보통 (~400 px)**, **선명 (~600 px)**, **원본 해상도** |
| **새로고침 (LUT 반영)** | Min/Max/Gamma를 바꾼 뒤 누르면 3D에 반영됩니다(LUT가 바뀌면 버튼이 강조됨). 색과 표시는 바로 반영됩니다. |

이미지 위에서 **왼쪽 드래그**는 위치 이동, **오른쪽 드래그**는 회전(좌우 = Y축,
위아래 = X축)입니다.

3D 구조는 이미지·Z 범위·Crop·미리보기 해상도·시점마다 한 번만 만들고, 돌릴
때는 다시 투영만 합니다(약 0.05초).

## LUT (투영 이미지)

- **LUT 탭과 연동 (한쪽에서 바꾸면 양쪽에 반영)**: 변경이 양쪽에 반영됩니다. Sum
  투영은 슬라이스 수만큼 범위를 곱해 적용합니다.
- 끄면 이 투영만의 LUT를 여기서 따로 조절합니다.
- **LUT 탭에서 다시 가져오기**.

## 저장

메뉴 막대의 **Tool › 스택** 메뉴에서 고르면 저장 옵션 창(아래 옵션)이 뜹니다.

> v0.59부터 아래 저장 항목은 메뉴가 아니라 **파일 › 내보내기…**의 **스택 투영** 항목에서 고릅니다([내보내기 창](17-export.md)). 저장되는 파일은 같습니다.

- **현재 투영 저장 (TIFF / MP4)…**: LUT와 마커가 들어간 RGB 이미지와, 투영값을
  담은 float32 ImageJ 스택. **타임시리즈는 모든 시점 저장**을 켜면 시점마다
  투영해 저장합니다.
- **3D 회전 시리즈 저장 (TIFF 스택 / MP4)…**: **회전** 시작 → 끝 각도,
  **간격**으로 TIFF 스택을 만듭니다.
- 저장 창에서 형식을 **MP4 동영상**으로 고르면 시점(또는 각도)마다 한 프레임인
  동영상으로 저장합니다(**MP4 프레임 속도**, fps).
- **3D는 원본 해상도로 저장**: 미리보기 해상도 대신 원본 해상도로 저장합니다.
