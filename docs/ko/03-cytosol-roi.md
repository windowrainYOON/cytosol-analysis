# 세포질 ROI 탭 (세포·핵·세포질 ROI)

[← 설명서 목차](README.md) · [English](../en/03-cytosol-roi.md)

메뉴 막대의 **세포질 ROI › 세포질 ROI 탭 열기**로 오른쪽에 이 탭을 열고 닫습니다. 이 탭의 저장과 불러오기도 같은 **세포질 ROI** 메뉴에 있습니다.

세포마다 ROI 하나를 핵과 함께 찾아, 세포마다 세 영역을 만듭니다: `cell`(세포
전체), `nuc`(핵), `cyto`(세포에서 핵을 뺀 세포질). 이 ROI는 다른 모든 분석
탭이 쓰고, ImageJ ROI 파일로 저장됩니다.

검출은 현재 Z 평면(또는 MIP)과 시점에서 합니다.

## 1. 채널 역할

- **핵**: 핵 채널(예: DAPI). 없으면 **없음**.
- **배경 신호**: LUT를 아주 밝게 올리면 세포질 전체가 채워져 보이는 어두운
  채널(자가형광이나 비특이 신호도 됩니다).

## 2. ROI 검출 (자동 / 수동)

**ROI 검출** 상자에는 **자동**과 **수동 (threshold)** 두 하위 탭이 있습니다.
선택한 탭의 방식으로 검출합니다. 크기 범위, 프레임 처리, 실시간 미리보기는 두
방식이 같이 씁니다.

'자동'이 붙은 설정은 모두 **자동** 체크박스로 켜고 끕니다. 자동일 때도 값
칸에는 실제로 쓰는(쓸) 값이 표시되고, 체크를 끄면 그 값에서부터 직접
고칩니다.

### 자동 탭

원리: 배경 신호 채널을 **배경 포화값**에서 포화시키고 핵과 합친 뒤, 초점이
맞은 핵마다 씨앗을 두고 watershed로 세포를 나눕니다. 그래서 세포마다 핵이
하나씩 들어갑니다(붙어 있는 핵은 먼저 나눕니다). 핵 채널이 없으면 세포 사이의
어두운 경계를 따라 나눕니다. 직접 정한 threshold도 이 알고리즘에 그대로 들어갑니다.

| 항목 | 의미 |
|---|---|
| **배경 포화값** ☑ 자동 | 배경 채널을 이 값부터 흰색으로 표시합니다. 자동 = 스무딩한 채널의 중앙값(칸에 표시). 세포마다 하나의 덩어리로 보일 때까지 자동을 끄고 낮추세요. |
| **검출용 합성 이미지 보기 (배경 밝게 + 핵)** | 검출기가 실제로 보는 이미지를 보여 줍니다. |
| **핵 threshold** ☑ 자동 | 약하게 스무딩한 핵 채널에서 이 값보다 밝으면 핵. 자동 = Otsu(칸에 표시). 끄면 숫자 칸이나 슬라이더로 정합니다. |
| **세포 threshold** ☑ 자동 | 배경 채널에서 이 값보다 밝으면 세포(세포 사이 틈은 더 어두워야 함). 배경 포화값보다 작게 두세요. |
| **threshold 영역 미리보기 (노랑: 세포, 파랑: 핵)** | 각 threshold를 넘는 영역을 이미지 위에 칠합니다. 슬라이더를 따라 바로 바뀝니다. |
| **스무딩** | 합친 이미지의 가우시안 스무딩(기본 0.8 µm). |
| **붙은 세포를 크기 범위에 맞게 나누기 · 합치기** | 아래 **세포 크기** 최대보다 큰 덩어리는 세포 사이 어두운 골을 따라 범위에 들어가는 가장 적은 개수로 나눕니다(씨앗: 거리 지도의 봉우리, 모자라면 k-means 중심; 핵이 있는 세포는 핵을 한 조각에 통째로 둡니다). 최소보다 작은 조각은 경계가 가장 약한 이웃과 합칩니다(합친 크기가 범위에 더 맞을 때만, 핵도 하나로 합침). 핵 크기 범위에도 똑같이 적용합니다. 기본은 꺼짐. |
| **가는 목으로 붙은 세포 자르기**, **목 폭 ≤** | 끝부분만 살짝 붙어 한 세포로 잡힌 경우(대개 한쪽 세포의 핵을 놓쳤을 때)를 자릅니다. 핵에서 세포 안쪽으로 같은 거리의 고리를 넓혀 가다가, 고리가 **목 폭** 이하의 좁은 틈을 지나 목보다 2.5배 이상 넓고 최소 세포 크기 이상인 부분으로 들어가면 그 틈을 목으로 보고, 목 부근에서 신호가 가장 어두운 경로를 따라 자릅니다. 그런 목이 없으면 윤곽에서 깊게 파인 오목점 두 개를 잇는 가장 짧은 선(같은 조건)으로 자릅니다. 잘린 쪽은 핵 없는 새 세포가 됩니다. 기본은 꺼짐, 목 폭 4 µm. |

### 수동 (threshold) 탭

가장 단순한 방식이며, 다른 알고리즘이 추가되어도 항상 남겨 둡니다.

- 배경 신호 채널에서 **세포 threshold 이상**인 연결된 영역이 그대로 세포 ROI가
  되고, 그 아래는 버립니다(ROI 안의 구멍은 채움: ImageJ 다각형 ROI에는 구멍이
  없음).
- 핵은 세포 안에서 **핵 threshold 이상**인 가장 큰 영역입니다.
- 스무딩·분할·병합은 하지 않고, 크기 범위와 프레임 처리만 적용합니다.
- 처음 열면 각 채널의 Otsu 값이 들어가고, 그 뒤로는 정한 값이 모든 이미지에
  그대로 쓰입니다. **threshold 영역 미리보기**(기본 켜짐)는 원래 합성 이미지 위에
  threshold 이상인 곳을 칠합니다.

### 두 방식 공통

| 항목 | 의미 |
|---|---|
| **세포 크기** 최소 – 최대 | 이 범위 밖의 세포는 버립니다(기본 80 µm² – 제한 없음). 칸 아래 슬라이더(로그 눈금, 1 – 100 000 µm²)로도 조절하며, 최대 슬라이더를 오른쪽 끝까지 밀면 **제한 없음**. |
| **핵 크기** 최소 – 최대 | 이 범위 밖의 핵은 핵으로 쓰지 않습니다(기본 15 µm² – 제한 없음). 슬라이더는 세포와 같습니다. |
| **☑ 자동 (이미지마다 추정)** | 켜면 이미지마다 따로 크기 범위를 정합니다. 그 이미지에서 크기 제한 없이 한 번 검출해(프레임에 걸친 세포 제외), 세포는 크기 중앙값 ÷ 4 ~ × 3, 핵은 ÷ 20 ~ × 3을 범위로 쓰고, 동떨어진 값(먼지, 붙은 덩어리; 로그 크기의 Tukey 기준, 사분위 ± 1.5 IQR)을 뺀 가장 작은 ~ 가장 큰 크기가 범위 밖이면 범위를 그만큼 넓힙니다. 이미지 한 장에는 온전한 세포가 몇 개뿐이라 가장 작은 ~ 가장 큰 값만 쓰면 범위가 너무 좁고, 작은 핵(가장자리, 흐린 핵)을 버리면 그 세포가 이웃 세포에 붙기 때문에 핵의 하한은 낮게 둡니다. 자동인 동안 칸은 잠기고 현재 이미지에 쓴 범위를 보여 줍니다. 상태 표시줄에도 이미지별 범위가 나옵니다. |
| **프레임에 걸친 세포** | **안쪽 경계로 자르기**(기본), **제외**, **그대로 두기**. |
| **안쪽 경계 여백** | 프레임에서 이만큼 안쪽에 새 경계를 그어 자릅니다(기본 1 µm). |
| **실시간 미리보기** | 켜면 threshold, 크기 범위, 스무딩 같은 값을 바꿀 때마다 현재 이미지에서 검출을 다시 돌려(뒤에서 실행, 이미지 한 장에 약 1초) 결과를 점선 ROI로 보여 줍니다. 그동안 기존 ROI 대신 미리보기가 보입니다. **ROI 검출**을 누르면 보이는 결과를 그대로 씁니다. 느리면 끄세요. 기본은 꺼짐. |

**ROI 검출 (현재 이미지)** 또는 **모든 이미지**(같은 설정, 채널은 이름으로
맞춤. ROI가 이미 있는 이미지도 다시 검출할지 묻습니다)로 실행합니다. 크기 범위가 수동(자동 꺼짐)이면 **모든 이미지**는 모든 이미지에 같은 범위를 적용할지 묻습니다. 예: 칸의 범위를 모든 이미지에, 아니오: 이미지마다 자동으로 추정한 범위를 씁니다. 상태
표시줄에 검출한 세포 수, 걸린 시간(모든 이미지는 이미지당 평균), 실제로 쓴
값이 나옵니다.

**검출 시간**(참고): 1024 × 1024 Zeiss 이미지(핵 + 배경 채널) 한 장에 약 0.7초,
크기 범위 맞추기를 켜면 약 0.8 – 1.1초, 1058 × 1058 TCF 형광 MIP는 약 2 – 4초
(클라우드 4코어 기준, Mac에서는 보통 더 빠름).

## 3. 확인 · 수정

| 도구 / 키 | 동작 |
|---|---|
| **선택/이동 (V)** | 세포를 클릭해 선택(목록에서 골라도 됨), 드래그는 화면 이동 |
| **더하기 (A)** | 자유곡선으로 영역을 그려 선택한 세포에 더함 |
| **빼기 (S)** | 그린 영역을 선택한 세포에서 뺌(선택이 없으면 모든 세포에서) |
| **새 세포 (N)** | 그린 영역을 새 세포로 추가. 핵 채널이 있으면 그 안에서 핵도 찾음 |
| **자르기 (C)** | 선을 그어 세포를 자름. 선택한 세포가 있으면 그 세포만, 없으면 선이 지나는 모든 세포. 핵이 있는 조각(없으면 가장 큰 조각)이 원래 번호를 갖고, 나머지는 새 세포가 됨. 선이 세포를 완전히 가로질러야 함 |
| **선택 세포 삭제** / `Delete` | 선택한 세포 삭제 |
| **되돌리기** / **다시 실행** | `Ctrl+Z` / `Ctrl+Shift+Z` |
| **번호 다시 매기기** | 세포 번호를 새로 매김 |
| **ROI 표시** / **핵 경계 표시** | ROI / 핵 윤곽 표시 |

세포는 항상 구멍 없는 한 덩어리입니다(ImageJ 다각형 ROI에는 구멍이 없음).
세포 안쪽을 깎으려면 세포 경계 바깥에서부터 그리세요. **새 세포**는 검출을
먼저 하지 않아도 바로 그릴 수 있습니다.

ROI 위에 마우스를 올리면 그 ROI 위에 이름과 면적이 뜹니다(`cellNNN`, 핵이 있으면
`nucNNN`, `cytoNNN`도). 실시간 미리보기 결과에서도 됩니다.

세포 목록에는 면적과, 프레임에서 잘렸는지(**프레임 안쪽으로 자름**) 또는
걸쳐 있는지(**프레임에 걸침**)가 나옵니다.

## 4. ImageJ ROI 파일

저장과 불러오기는 메뉴 막대의 **세포질 ROI** 메뉴에서 합니다.

- 저장할 ROI 고르기(메뉴의 체크 항목): **저장할 ROI: 세포 전체**(`cellNNN`, 세포
  다각형), **핵**(`nucNNN`), **세포질 (핵 제외)**(`cytoNNN`, 세포에서 핵을 뺀
  composite ROI).
- **ROI 저장 (현재 이미지)…**: `.zip` = ImageJ RoiSet 하나(ROI Manager › Open),
  `.roi` = ROI마다 `.roi` 파일 하나.
- **모든 이미지 ROI 저장 (폴더)…**: 이미지마다 RoiSet 하나와, 세포·핵·세포질
  면적을 담은 `cell_rois.csv`. **파일 › 이미지별 폴더에 나눠 저장**을
  켜면 이미지마다 폴더에 넣습니다.
- **ROI 불러오기…**(또는 **파일 › 불러오기 (자동 인식)…**)에서 `.zip` / `.roi`를 고르면 세포 ROI로
  알아보고 현재 이미지(이미지 ID가 맞는 이미지가 열려 있으면 그 이미지)에
  불러옵니다. 이미 세포가 있으면 바꿀지 먼저 묻습니다.

## 5. 세포 강도 측정

**측정할 영역**: **세포 전체**, **핵**, **세포질**. 표에는 세포·영역·채널마다
현재 평면과 시점의 원본값에 대한 ImageJ Measure 값(Mean, 선택적으로 StdDev,
Min, Max, IntDen, RawIntDen)이 나옵니다. ROI를 고칠 때마다 다시 계산합니다.

파일: 이미지마다 `<이름>_cell_intensity.csv`, 전체 `cell_intensity.csv`. 표,
일괄 측정, 저장 방법은 [측정 결과 표](09-intensity.md#측정-결과-표)를 보세요.

## 팁

- 세포는 핵 하나에서 자라나므로, 세포가 잘못 나오면 먼저
  **threshold 영역 미리보기**로 핵을 보세요. 핵이 둘로 갈라지면 세포도 둘이
  되고, 핵 두 개가 하나로 잡히면 세포도 하나가 됩니다. 붙은 세포가 하나로
  나오면 **세포 크기** 범위를 정하고 **붙은 세포를 크기 범위에 맞게 나누기 · 합치기**를
  켜 보세요(**실시간 미리보기**로 바로 확인). 그다음
  **검출용 합성 이미지 보기**로 세포마다 한 덩어리인지 확인하고, 아니면
  **배경 포화값**을 낮추거나 세포 threshold를 수동으로 정하세요.
- 남은 세포는 **더하기**, **빼기**, **새 세포**, **자르기**로 직접 고칩니다. 끝이 붙어 한 세포로 잡힌 경우는 **가는 목으로 붙은 세포 자르기**를 켜거나 **자르기**로 선을 그어 나눕니다.
- 핵을 찾지 못하면 상태 표시줄에 알리고 핵 없이 세포를 나눕니다.
- 원하는 대로 잘 안 나오면 **수동 (threshold)** 탭으로 threshold 이상만 ROI로 잡을 수 있습니다.
- Python: `cytosol.cellroi.segment_cells(bg_plane, nucleus_plane, pixel_um, RoiParams())`,
  수동 방식은 `threshold_cells(bg_plane, nucleus_plane, pixel_um, cell_thr, nuc_thr, RoiParams())`.
