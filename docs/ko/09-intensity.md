# 강도 측정 탭 (논리식 영역의 강도)과 측정 결과 표

[← 설명서 목차](README.md) · [English](../en/09-intensity.md)

메뉴 막대의 **Tool › 강도 측정 › 강도 측정 탭 열기**로 오른쪽에 이 탭을 열고 닫습니다. 이 탭의 저장과 불러오기도 같은 **강도 측정** 메뉴에 있습니다.

## 강도 측정 탭

세포 ROI([세포질 ROI 탭](03-cytosol-roi.md))와 입자 ROI([입자 ROI 탭](04-particle-roi.md))를
논리식으로 묶어 세포마다 새 영역을 만들고, 그 영역의 채널별 원본값을 잽니다(ImageJ
Measure와 같은 값). 세포·핵·세포질만 따로 재는 것은 세포질 ROI 탭에서, 입자는 입자
ROI 탭에서 합니다.

### 논리식 영역

식을 하나 이상, 세미콜론(;)으로 나눠 씁니다.

| 이름 | 영역 |
|---|---|
| `cell` | 세포 전체 |
| `nuc` | 핵 |
| `cyto` | 세포질 (세포 − 핵) |
| `particle` | 그 세포의 입자 |

| 연산 | 의미 |
|---|---|
| `&` | 교집합 |
| `\|` | 합집합 |
| `-` | 빼기 |
| `( )` | 괄호 |

예:

```
cyto - particle;  cell & particle;  (cell - nuc) | particle
```

- `cyto - particle`: 입자 바깥의 세포질(묽은 상).
- `cell & particle`: 세포 안의 입자.
- `nuc & particle`: 핵 안의 입자.

식이 틀리면 입력 칸 아래에 알려 줍니다. **이미지에 영역 표시 (청록색)**은 선택한
세포의 영역을 칠해 보여 줍니다.

입자를 이미지 전체에서 찾은 경우(입자 ROI 탭 **이미지 전체**)에도 세포마다 이 식으로
나누며, 세포나 핵 경계에 걸친 입자 조각은 각 쪽으로 나뉩니다.

파일: `<이름>_intensity.csv`, `intensity.csv`, 그리고 `<이름>_regions.zip`(세포와
영역마다 ImageJ ROI 하나, `rgnCCC-R`, 식은 `region` 속성에 저장).

### 핵 → 세포막 등거리 띠

세포질을 핵에서의 거리가 같은 띠(등거리선 사이)로 나누고 띠마다 채널별 강도를 잽니다.
핵이 있는 세포만 잽니다.

| 설정 | 설명 |
|---|---|
| **거리** | **상대 거리**(기본): 핵에서의 거리 ÷ (핵에서의 거리 + 세포 경계까지의 거리). 세포 크기와 상관없이 0 = 핵 경계, 1 = 세포 경계. **핵 경계에서의 거리 (µm)**: 핵 윤곽에서 잰 실제 거리(보정 정보가 없으면 픽셀). 프레임에서 잘린 세포는 잘린 경계를 세포 경계로 봅니다. |
| **범위** | 잴 거리 범위. 상대 거리는 기본 0 – 1, µm는 0 – 10. |
| **띠 개수** | 범위를 같은 폭으로 나눌 개수 (기본 10). |
| **이미지에 띠 표시** | 켜면 논리식 영역 대신 띠의 경계를 청록색으로 그립니다. |

아래 측정 표(측정값 선택, 현재 이미지 / 모든 이미지, 자동 갱신)는 논리식 영역의 표와
같은 방식입니다. 행은 세포와 띠마다 하나이고 열은 `band`, `distance_rel`(또는
`distance_µm`, 띠 가운데 값)과 `_from`, `_to`, 면적, 채널별 측정값입니다. 입자를 정했으면
띠마다 `n_particles`(중심이 그 띠에 있는 입자 수), `particle_area_um2`,
`particle_area_fraction`, 채널별 `_particle_Mean`(띠 안 입자 픽셀의 평균)도 들어갑니다.

**그래프**: x, y에 측정한 열 중 아무거나 고를 수 있습니다(기본 x = 거리, y = 첫 채널의
Mean). 회색 선은 세포마다, 빨간 선과 띠는 띠별 세포 평균 ± SD입니다. 표 보기를 **모든
이미지**로 바꾸면 일괄 측정 결과를 그립니다.

저장(**강도 측정** 메뉴): **등거리 띠 CSV 저장 (현재 이미지)…**(`<이름>_bands.csv`),
**등거리 띠: 모든 이미지 측정 + 저장 (폴더)…**(이미지별 `<이름>_bands.csv`와 전체
`bands.csv`), **등거리 띠 그래프 저장 (PNG / PDF / SVG / TIFF)…**. **모든 분석 결과 통합
저장**에도 `<이름>_bands.csv`가 들어갑니다.

## 측정 결과 표

세포질 ROI, 입자 ROI, 강도 측정 탭은 같은 측정 묶음을 씁니다.

### 측정값 (채널마다)

- **Mean**(기본 켜짐), **StdDev**, **Min**, **Max**, **IntDen**, **RawIntDen**:
  ImageJ Measure의 정의 그대로, 현재 Z 평면(또는 MIP)과 시점의 원본값에서 잽니다.
  면적은 항상 들어갑니다.
- **측정할 채널**: 현재 이미지의 채널마다 체크박스가 있고, 체크한 채널만 표와 CSV에
  들어갑니다(기본은 모두 체크). 끈 채널은 이름으로 기억해서 같은 이름의 채널이 있는
  모든 이미지와 일괄 측정·저장에 적용되고, 프로젝트에도 저장됩니다. 탭마다 따로
  고르며, 검출에 쓰는 채널(핵·배경·입자 채널)과는 상관없습니다.
- **LUT에서 숨긴 채널 제외**: LUT 탭에서 숨긴 채널은 빼기.

### 강도 측정 결과

- 보기 선택: **현재 이미지**, **모든 이미지 (일괄 측정 결과)**. 입자 ROI 탭에는
  **요약: 이미지별** / **요약: 그룹별**도 있습니다.
- **자동 갱신**(기본 켜짐): ROI·Z·시점·설정이 바뀔 때마다 현재 이미지를 다시
  계산합니다. **지금 측정 (현재 이미지)**는 바로 한 번 잽니다.
- 행을 누르면 그 세포가 이미지에서 선택됩니다.
- **모든 이미지 측정**: ROI가 있는 모든 이미지에서 같은 영역·측정값으로 잽니다
  (입자는 각 이미지의 입자 설정대로). **일괄 측정에 모든 시점 포함**을 켜면 모든
  시점을 잽니다.
- 행에는 `image`, `image_id`, `group`, `cell`, `region`, `plane`, 시점, 그리고 채널과
  측정값마다 한 열이 있습니다.

### 저장

측정 표를 가진 세 탭 모두 메뉴 막대 **Tool** 아래 자기 메뉴(**세포질 ROI**, **입자 ROI**,
**강도 측정**)에서 저장합니다.

- **측정 CSV 저장 (현재 이미지)…**.
- **모든 이미지 측정 + 저장 (폴더)…**: 모든 이미지를 다시 잰 뒤 전체 CSV
  (`<suffix>.csv`)와, 이미지마다 `<이름>_<ID>` 폴더에 `<이름>_<suffix>.csv`를
  저장합니다(입자 ROI 탭은 요약도, 그리고 `image_groups.csv`).
- **파일 › 측정·프로파일 저장 시 ROI와 ROI가 그려진 이미지(.png)도
  함께**(기본 켜짐, 모든 탭 공통):
  `<이름>_RoiSet.zip`(세포·핵·세포질), 입자를 쓰면 `<이름>_particles.zip`, 논리
  영역 ROI, `<이름>_image.png`(현재 LUT 이미지 위에 ROI 경계)도 함께 저장합니다.

| 탭 | `<suffix>` |
|---|---|
| 세포질 ROI | `cell_intensity` |
| 입자 ROI | `particle_intensity`(세포별) 또는 `particle_shape`(입자마다) |
| 강도 측정 | `intensity` |
