# LUT · 내보내기 탭 (표시와 저장)

[← 설명서 목차](README.md) · [English](../en/02-lut-export.md)

채널마다 표시 방법(LUT)을 정하고 이미지를 저장하는 탭입니다. 여기서 정한
LUT는 미리보기, 모든 RGB 저장, 스택 탭(연동할 때), Figure 창에 그대로
쓰입니다.

## 채널 표시

**채널 표시**: 채널마다 체크박스 하나씩, 한 줄로 놓여 있고 **모두 켜기** /
**모두 끄기**가 있습니다. 숨긴 채널은 미리보기와 합성 이미지에서 빠지며,
측정에서도 뺄 수 있습니다(**LUT에서 숨긴 채널 제외**).

## 채널 LUT (채널마다 한 칸)

| 항목 | 하는 일 |
|---|---|
| 색 버튼 | 채널 색 고르기 |
| **Auto** | 현재 이미지의 0.5–99.8 백분위수로 Min/Max 설정 |
| **Min/Max** | 현재 이미지 데이터의 최소값–최대값으로 설정 |
| 히스토그램 | 드래그해서 Min/Max 설정 |
| **Min**, **Max** | 슬라이더 또는 숫자 |
| **Gamma** | 0.1–5 (1 = 선형) |
| **전체 이미지에 적용** | 이 채널의 LUT를 모든 이미지의 같은 채널에 적용 |

슬라이더와 히스토그램의 범위는 메타데이터에서 읽은, 파일이 담을 수 있는 값의
범위입니다(예: 12-bit는 0–4095, 8-bit는 0–255). 히스토그램 아래에
**파일 범위**로 표시되며, 그 정보가 없는 파일은 **데이터 범위**로 나옵니다.
처음 Min/Max는 자동 백분위수 범위입니다.

이미지 사이에서 채널은 이름으로 맞추고, 같은 종류·같은 채널 수의 파일끼리만
순서로 맞춥니다.

## 일괄 적용

- **모든 채널 LUT를 전체 이미지에 적용**.
- **색상도 함께 적용**: 끄면 Min/Max/Gamma만 복사하고 각 이미지의 색은
  그대로 둡니다.
- **LUT 프리셋 저장… / 불러오기…**: LUT를 JSON 파일로 저장하고 불러옵니다.

## 일괄 저장 (TIFF / MP4)

1. **범위**: **전체 이미지**(`<이름>_full_*`)와/또는 **Crop 영역 각각**
   (`<이름>_crop1_*`, `<이름>_crop2_*`, …).
2. 저장할 것:
   - **합성 RGB (LUT 적용)**: 현재 LUT와 마커(scale bar, 타임 스탬프), µm
     보정이 들어간 8-bit RGB.
   - **채널별 RGB**: 채널마다 RGB 이미지 하나.
   - **원본값 스택 (ImageJ, 모든 Z)**: 모든 Z의 원본값을 담은 ImageJ
     hyperstack. 채널 LUT, 표시 범위, µm 보정이 들어 있어 Fiji에서 바로 측정할
     수 있습니다.
3. 타임시리즈:
   - **타임시리즈는 모든 시점 저장 (끄면 현재 시점만)**: RGB는 시점마다
     타임 스탬프가 찍힌 T 프레임 스택, 원본값 스택은 TZCYX hyperstack이 됩니다.
   - **타임시리즈 RGB 형식**: **TIFF**, **MP4 (동영상)**(H.264, 시점마다 한
     프레임, 옆 칸의 fps), 또는 **TIFF + MP4**. 시점이 하나인 이미지와 원본값
     스택은 항상 TIFF입니다.
4. **이미지별 폴더에 나눠 저장**(기본 켜짐, 세포질 ROI 탭과 공유): 이미지마다
   `<고른 폴더>/<이름>_<이미지 ID>/`에 저장합니다.
5. **현재 이미지만 저장…** 또는 **모든 이미지 저장…**을 누르고 폴더를
   고릅니다.

CZI의 bleach 영역은 저장할 때마다 `<이름>_bleach_rois.zip`으로 함께 저장되고,
[마커 탭](05-markers.md)에서 켜면 RGB 이미지에도 그려집니다.

## 모든 데이터 일괄 저장

**모든 데이터 일괄 저장 (TIFF + ROI, 이미지별 폴더)…**(**파일** 메뉴,
`Ctrl+Shift+E`)는 이미지마다 폴더를 하나 만들고, 그 이미지에 있는 것을 모두
넣습니다.

- 위의 TIFF/MP4,
- `<이름>_RoiSet.zip`과 `<이름>_cell_rois.csv`(세포 ROI와 면적),
- 세포·입자·논리 영역 강도 CSV와 `<이름>_particles.zip`,
- `<이름>_info.csv`(이미지 정보), `<이름>_coloc2.csv`(Coloc 2를 계산했으면).

고른 폴더 맨 위에는 전체를 합친 `cell_rois.csv`, `coloc2.csv`, 강도 CSV와
요약, `image_groups.csv`가 저장됩니다.

파일 이름 전체는 [저장되는 파일](12-output-files.md)을 보세요.
