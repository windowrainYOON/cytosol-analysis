# Figure 창 (Figure 만들기)

[← 설명서 목차](README.md) · [English](../en/11-figure.md)

이미지를 행·열 이름이 있는 표로 배치하고 확대 inset과 scale bar를 넣어 논문
figure를 만듭니다. **Figure › Figure 창 열기…** 또는 `Ctrl+Shift+F`로 엽니다. Figure 저장과
inset ROI 저장·불러오기는 이 창 안의 버튼으로 합니다. Figure 구성은 프로젝트
파일에도 저장됩니다.

칸에는 불러온 이미지가 현재 LUT로 나옵니다. 메인 창에서 바꾼 내용은 Figure 창으로
돌아오면 반영됩니다.

## 표

- **행 추가 / 열 추가**, **행 삭제 / 열 삭제**, **행 ▲ / 행 ▼ / 열 ◀ / 열 ▶**(순서 이동).
- **행·열 머리글을 더블클릭**하면 이름(Enter로 줄바꿈)과 글자 색(**색상…**,
  **기본 색상**)을 고칩니다. 머리글을 우클릭하면 **이름/색상 수정…**,
  **위에/아래에 행 삽입**, **왼쪽에/오른쪽에 열 삽입**.
- 칸을 클릭해 선택하면 아래 패널이 그 칸에 적용됩니다.

## 선택한 칸

| 항목 | 하는 일 |
|---|---|
| **이미지** | 이 칸에 넣을 이미지 |
| **영역** | **전체 이미지** 또는 그 이미지의 Crop 영역 |
| **파일…** | 대신 PNG/TIFF 파일을 넣기(예: 이전에 저장한 이미지) |
| **메인 창 표시 채널 따르기** | 메인 창에서 보이는 채널을 그대로 사용 |
| **채널 조합** | 채널마다 체크박스. 이 칸만의 조합을 자유롭게(위 옵션은 꺼짐). **모두 켜기 / 모두 끄기**. 체크박스 옆 드롭다운은 그 채널의 밝기 레벨(아래 **밝기 (이 칸만)**) |
| **이 행을 채널별 + Merged로 채우기** | 채널마다 한 열, 마지막 열에 합성 이미지 |
| **열 이름을 채널 이름/색으로** | 이 행의 채널 이름과 LUT 색으로 열 이름 붙이기 |
| **이 행의 다른 칸도 같은 이미지/영역으로** | 채널 선택은 두고 이미지와 영역만 같게 |
| **칸 비우기** | 칸 비우기 |

## 밝기 (이 칸만)

칸마다(또는 그 칸의 확대 영역마다) 채널 밝기(Min/Max)를 따로 정합니다. 처음에는
모두 **자동**이라 LUT 탭 값을 그대로 쓰고, LUT 탭을 바꾸면 따라 바뀝니다. 자동일
때도 칸에는 지금 쓰는 값이 보입니다. LUT 탭 값은 바뀌지 않습니다.

- **조절할 곳**: **이 칸 전체** 또는 **확대 영역 N**. 확대 칸(다른 칸에 따로 넣은
  확대본)을 고르면 그 확대 영역을 조절합니다. 확대 영역의 **자동**은 칸 값을
  따릅니다.
- 보이는 채널마다 한 줄: **자동** 체크박스를 끄면 이 칸만의 값이 되고, **Min / Max**
  칸과 그 아래 슬라이더로 조절합니다. **Auto**는 이 칸(확대 영역)에 보이는 부분의
  밝기 분포로 Min/Max를 정합니다.
- **모두 자동으로**: 여기서 조절한 값을 지웁니다.

**Merged 칸에 조절한 레벨 넣기**: **채널 조합** 체크박스 옆 드롭다운에서 채널마다
고릅니다.

| 드롭다운 | 그 채널에 쓰는 값 |
|---|---|
| **LUT 탭 (자동)** | LUT 탭 값(기본) |
| **이 칸에서 조절** | 이 칸에서 따로 정한 값 |
| **행 r, 열 c 칸 (min–max)** / **… 확대 영역 k** | 다른 칸이나 확대 영역에서 조절한 값(같은 이미지, 또는 같은 이름의 채널). 그 칸을 다시 조절하면 따라 바뀝니다 |

예: CH1 칸과 CH2 칸을 각각 밝게 조절한 뒤, Merged 칸의 CH1 드롭다운에서 CH1 칸을
고르면 Merged에 그 레벨이 들어가고, CH2는 **LUT 탭 (자동)**으로 두면 원래 값입니다.

## 확대 영역 (inset)

1. **확대 영역 그리기 (드래그)**를 누르고 칸 미리보기 위에서 상자를 드래그합니다
   (`Shift`+드래그: 정사각형). 그리기 모드가 아닐 때 기존 상자를 드래그하면
   옮겨집니다.
2. **표시 방식**:
   - **이미지 안 (모서리에 겹쳐서)**: 확대본을 **모서리**(왼쪽 위 / 오른쪽 위 /
     왼쪽 아래 / 오른쪽 아래)에 **크기**(칸 너비 대비 %)로 넣습니다.
   - **다른 칸에 따로**: 확대본을 다른 칸에 넣습니다. **넣을 칸**은 아무 칸이나,
     또는 **오른쪽에 새 열 삽입** / **아래에 새 행 삽입**. 기본은 오른쪽의 빈 칸,
     없으면 새 열입니다. 이미 이미지가 있는 칸을 고르면 덮어씁니다.
3. **이 행 전체에 적용** / **이 열 전체에 적용**: 크기가 같은 이미지가 든 그
   행/열의 모든 칸에 같은 inset을 넣습니다(따로 넣는 확대 칸도 같은 간격 유지.
   예: 이미지 행 아래에 확대 행).
4. **삭제**: 선택한 inset 삭제.

### 같은 크기, 복사·붙여넣기

- **같은 크기로 그리기**: 클릭이나 드래그한 곳에 옆에 적은 크기(px)의 상자가
  놓입니다. 다른 칸에서도 같은 크기입니다.
- **모든 칸에 이 크기 적용**: figure의 모든 inset을 이 크기로 바꿉니다(상자
  중심은 그대로).
- **영역 복사** → **붙여넣기**: 선택한 칸의 원본 이미지 같은 위치에 붙입니다.
  **여러 칸에 붙여넣기…**는 고른 여러 칸에 한꺼번에(선택하면 **그 칸의 기존
  확대 영역 지우고 넣기**).
- **ROI 저장…**: 선택한 inset을 ImageJ `.roi`로, `.zip`을 고르면 이 칸의 모든
  inset을 저장합니다. 좌표가 원본 이미지 기준이라 ImageJ에서 바로 열립니다.
  **ROI 불러오기…**는 `.roi` / `.zip`의 사각형 범위를 inset으로 추가합니다.

## 레이아웃

| 항목 | 의미 |
|---|---|
| **배경** | **검은 배경** / **흰 배경**(글자는 흰색/검은색으로 바뀜), **칸 테두리** |
| **칸 너비** | inch |
| **세로/가로 비** | **자동 (첫 이미지)** = 첫 이미지 비율 |
| **칸 간격** | inch |
| **글꼴**, **글자 크기**, **굵게** | 이름 글꼴, 크기(pt), 굵게 |
| **Scale bar** | 모든 칸에 같은 길이(**자동** 또는 µm 고정)와 위치 |
| **칸마다 길이 글자** | 칸마다 길이 글자 표시 |
| **아래에 "(Scale bar = … µm)"** | 대신 figure 아래에 설명 글 |
| **Inset에도 scale bar** | inset에도 scale bar(따로 길이 지정) |
| **상자 색** | inset 상자 색 |

## 내보내기

**해상도**(기본 300 dpi)를 정하고 **Figure 저장… (PNG / TIFF / PDF / SVG)**
(`Ctrl+S`). PNG·TIFF는 정한 dpi로, PDF·SVG는 글자를 편집할 수 있게 저장합니다.
