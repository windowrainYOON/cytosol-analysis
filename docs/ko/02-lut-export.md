# LUT 탭과 이미지 내보내기

[← 설명서 목차](README.md) · [English](../en/02-lut-export.md)

**LUT** 탭은 채널마다 표시 방법(LUT)을 정하는 탭입니다(항상 열려 있음). 탭은
한 페이지로 스크롤되며, 맨 위에 **모든 채널 LUT를 전체 이미지에 적용**, 그 아래
채널 표시, 그다음 채널마다 LUT가 있습니다. [마커 설정](05-markers.md)은 따로 **마커** 탭에 있습니다. 이미지 저장은
**파일 › 내보내기…**(`Ctrl+E`) 창에서 합니다([내보내기 창](17-export.md)). 여기서 정한
LUT는 미리보기, 모든 RGB 저장, 스택 탭(연동할 때), Figure 창에 그대로
쓰입니다.

## 채널 표시

**채널 표시**: 채널마다 체크박스 하나씩, 한 줄로 놓여 있고 **모두 켜기** /
**모두 끄기**가 있습니다. 숨긴 채널은 미리보기와 합성 이미지에서 빠지며,
측정에서도 뺄 수 있습니다(**LUT에서 숨긴 채널 제외**).

## 채널 LUT (채널마다 한 칸)

| 항목 | 하는 일 |
|---|---|
| 색 버튼 | 채널 색 고르기 |
| **Auto** | 현재 이미지의 0.5–99.8 백분위수로 Min/Max 설정 |
| **Min/Max** | 현재 이미지 데이터의 최소값–최대값으로 설정 |
| 히스토그램 | 드래그해서 Min/Max 설정 |
| **Min**, **Max** | 슬라이더 또는 숫자 |
| **Gamma** | 0.1–5 (1 = 선형) |
| **전체 이미지에 적용** | 이 채널의 LUT를 모든 이미지의 같은 채널에 적용 |

슬라이더와 히스토그램의 범위는 메타데이터에서 읽은, 파일이 담을 수 있는 값의
범위입니다(예: 12-bit는 0–4095, 8-bit는 0–255). 히스토그램 아래에
**파일 범위**로 표시되며, 그 정보가 없는 파일은 **데이터 범위**로 나옵니다.
처음 Min/Max는 자동 백분위수 범위입니다.

이미지 사이에서 채널은 이름으로 맞추고, 같은 종류·같은 채널 수의 파일끼리만
순서로 맞춥니다.

## 일괄 적용

- **모든 채널 LUT를 전체 이미지에 적용**.
- **색상도 함께 적용**: 끄면 Min/Max/Gamma만 복사하고 각 이미지의 색은
  그대로 둡니다.
- LUT 프리셋: **LUT › LUT 프리셋 저장…**으로 현재 이미지의 LUT를 JSON 파일로
  저장하고, **LUT › LUT 프리셋 불러오기…**(또는 **파일 › 불러오기 (자동 인식)…**)로
  그 파일을 고르면 모든 이미지에 적용합니다.

## 이미지 저장

이미지(합성 RGB, 채널별 RGB, 원본값 스택, 타임시리즈 TIFF / MP4)와 Crop 영역은
**파일 › 내보내기…**(`Ctrl+E`)의 **이미지**, **Crop 영역** 항목에서 저장합니다. 예전의
**LUT › 이미지 내보내기**와 **모든 분석 결과 통합 저장**은 이 창 하나로 합쳐졌습니다.
항목과 파일 이름은 [내보내기 창](17-export.md)과 [저장되는 파일](12-output-files.md)을
보세요.

CZI의 bleach 영역은 이미지를 저장할 때마다 `<이름>_bleach_rois.zip`으로 함께 저장되고,
[마커 탭](05-markers.md)에서 켜면 RGB 이미지에도 그려집니다.
