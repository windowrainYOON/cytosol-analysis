# 파이프라인 (v0.73)

[← 설명서 목차](README.md) · [English](../en/24-pipeline.md)

파이프라인은 **순서가 있는 단계 목록 + 단계마다 저장된 설정 + 중간의 검토(첨삭) 멈춤점**입니다.
데이터 폴더의 모든 이미지에 단계를 하나씩 돌리고(한 단계를 모든 이미지에 끝낸 뒤 다음 단계),
검토 단계에서 멈춰 ROI를 고친 다음 이어 가며, 끝나면 데이터 폴더의 상위 폴더 › `Processed/`에
결과 폴더를 만듭니다. 예전의 **일괄 분석**은 "검토 없는 파이프라인"으로 이리로 합쳐졌고,
**강도 측정 탭**은 파이프라인의 **연산**(더하기 · 빼기 · 겹침)과 **측정 › 세기**로 옮겨졌습니다.

**파일 › 파이프라인…** (`⇧⌘P`)으로 창을 엽니다. **파일 › 새 파이프라인**(v0.74)은 단계가 하나도 없는
빈 파이프라인으로 창을 엽니다(처음 여는 창도 빈 상태). **파일 › 파이프라인 보관함…**은 저장한
파이프라인과 기본 프리셋을 카드로 보여 줍니다. 카드마다 단계가 위에서 아래로 칩으로 이어지고(↓), 그룹
이름(검출 · 추적 · 측정 …)은 그 그룹 첫 단계 옆에, 검토 단계는 파란 칩, 꺼진 단계는 흐리게 보입니다. `.cypipe` 파일이나 예전 일괄 분석 설정(`.json`)을
**불러오기**로 열어도 이 창이 뜹니다.

## 창 구성

- **위 툴바**: **파이프라인** (보관함에서 고르기), **저장…** (저장 / 다른 이름으로 저장 /
  파일에서 불러오기 / 복제 / 보관함…), **데이터** 폴더 (비우면 지금 열린 이미지), **폴더 선택…**,
  **실행** (파란 버튼).
- 그 아래 줄: `14단계 · object 9개 · 검토 1번` 칩 (문제가 있으면 주황 칩과 `문제 n`) 과 결과 폴더 미리 보기.
- **왼쪽 사이드바**: **＋ 단계 추가** (묶음별 메뉴) 와 번호 붙은 단계 목록. 단계는 묶음 제목 아래
  **시작 → 검출 → 추적 → 연산 → 측정 → 끝** 순서로 늘 정렬되고, 검토 단계는 바로 앞 단계 뒤에 붙습니다.
  - 끌어서 순서를 바꿉니다. **같은 묶음 안에서만** 움직이고, 그 자리에서 쓸 object가 아직 없으면
    옮기지 않고 상태 막대에 이유를 적습니다. `⌥↑` / `⌥↓`도 같습니다.
  - 오른쪽 클릭: 위로 · 아래로 · 복제 · 끄기 (건너뛰기) · **단계 삭제…**.
  - 앞 단계에 없는 object를 쓰는 단계에는 `⚠ object 없음`이 붙습니다 (툴팁에 이유).
- **오른쪽**: 고른 단계의 설정 카드.

## object

검출 · 추적 · 연산이 만드는 ROI는 모두 **이름이 붙은 object**입니다. 세포질 ROI 검출은
**세포 · 핵 · 세포질**(= 세포 − 핵), 입자 ROI는 **입자**, mitoROI는 **미토 조각**,
입자 추적은 **입자 트랙**, 세포질 강도 추적은 **세포 트랙**을 만들고, 연산 단계는 사용자가
정한 이름의 새 object를 만듭니다. 각 object는 부모 세포 번호를 물려받으므로 뒤 단계의
"같은 세포 번호끼리" 짝 맞추기와 측정 표의 `cell` 열에 그대로 쓰입니다.

## 단계 종류

| 묶음 | 단계 | 하는 일 |
|---|---|---|
| 시작 | 불러오기, 자동 그룹 | 폴더 · 파일 이름 패턴 · 하위 폴더 포함 / 이름 끝 번호를 뺀 같은 이름끼리 그룹 |
| 검출 | 세포 · 핵 (세포질 ROI), 입자 (입자 ROI), 미토 ROI (mitoROI) | 그 탭의 검출 설정으로 이미지마다 찾기 |
| 추적 | 입자 추적, 세포질 강도 추적 | 시간축이 있는 이미지에서 프레임마다 찾고 잇기 |
| 연산 | 연산 | 입력 object · 기준 · 동작 · 결과 이름 (아래) |
| 측정 | 세기 (ImageJ Measure), 개수 · 밀도, 등거리 띠, Coloc 2, FRAP 회복, 미토 형태 (MiNA) | object × 채널 → 표 |
| 사람 | 검토 (사용자 첨삭) | 멈추고 고른 이미지의 ROI를 고친 뒤 이어 가기 |
| 끝 | 그래프, 저장 · 내보내기 | 그래프 다시 그리기, 결과 폴더 |

### 탭 설정을 쓰는 단계

검출 · 추적 · 등거리 띠 · Coloc 2 · FRAP 단계는 그 탭의 설정을 씁니다.

- **설정 출처**: **이 단계에 저장된 설정** (단계를 추가할 때 탭의 지금 설정을 복사해 둠; 탭에서 다른
  이미지를 만져도 파이프라인 결과는 바뀌지 않음) 또는 **탭의 지금 설정** (실행할 때 탭 설정을 씀,
  예전 일괄 분석과 같음).
- **탭 설정 가져오기**: 지금 탭 설정을 이 단계에 복사합니다.
- **탭에서 열어 고치기…**: 그 탭을 이 단계 설정으로 열고 캔버스 위에 「파이프라인 n단계 설정 편집 중」
  띠를 띄웁니다. 미리 보기 · 실시간 검출 등 탭의 모든 기능으로 맞춘 뒤 **단계에 반영**을 누르면
  단계에 저장되고 탭은 원래 설정으로 돌아갑니다 (**취소**는 그대로 돌림).
- **이미 결과가 있으면**: **다시 찾기** 또는 **그대로 두기** (검토에서 고친 ROI를 지키려면 그대로 두기).

### 연산

연산 단계는 모두 같은 네 칸입니다.

1. **입력 object**: 앞에서 만든 object.
2. **기준**: **모두** 또는 **조건에 맞는 것만**. 조건은 줄마다 [항목] [≥ · ≤ · > · < · = · 범위 · 예 · 아니오] [값]
   이고 **＋ 조건 추가**, **조건 묶기**(모든 조건 / 하나라도)로 묶습니다. 항목:
   - 크기 · 모양: `Area` (µm²), `Perimeter`, `Feret` (µm), `Circularity`, `Solidity`, `AR`
   - 세기: `Mean:<채널>`, `IntDen:<채널>`; 값에 `bg*1.5`라고 쓰면 그 채널 배경(세포 밖 중앙값)의 1.5배
   - 다른 object와: `overlap:<object>` (겹친 %), `inside:<object>` (중심이 안에 있음)
   - `edge` (이미지 가장자리에 닿음)
   - 트랙: `frames` (프레임 수), `divided` (분열), `edge`, `change:thr` (끝 / 처음 세기 비), `class`
     (입자 추적 트랙 분류, 예: `signal`; 세포 트랙은 세포질 강도 추적의 필터 이름)
3. **동작**: 맞는 것만 남기기 · 맞는 것 버리기 · 빼기 (무엇을) · 더하기 (무엇과) · 겹친 부분만 (무엇과) ·
   합치기 (부모마다 하나) · 넓히기 / 줄이기 (µm) · 고리 (안 – 밖 µm) · 등거리 띠 (n개).
   빼기 · 더하기 · 겹침은 **상대 object**와 **짝 맞추기**(같은 세포 번호끼리 / 겹치는 것끼리 / 이미지 전체)를
   고릅니다. 예: 세포질 = 세포 **빼기** 핵 (같은 세포 번호끼리) = 강도 측정 탭의 영역식 `cyto = cell − nuc`.
   세포를 둘러싼 고리는 다른 세포를 피하므로 배경 고리로 씁니다. 등거리 띠는 핵 → 세포막 상대 거리로 n개.
4. **결과 이름**: 새 object 이름. 남기기 · 버리기에서는 **안 맞는 것 이름**을 주면 나머지도 따로 object가
   됩니다 (예: 「신호 오른 세포」와 「나머지」).

아래 **미리 보기**는 현재 이미지에서 이 단계까지의 연산 결과를 칠해 보여 주고, `세포질 2개` 같은 칩으로
개수를 알려 줍니다 (검출 단계를 한 번 돌린 이미지에서).

### 측정

- **세기 (ImageJ Measure)**: **대상 (object × 채널)** 줄마다 object와 잴 채널 칩(모두 켜면 모든 채널),
  **＋ 대상 추가**. **측정 항목** 칩: Area, Mean, StdDev, Min, Max, Median, IntDen, RawIntDen, Perimeter,
  Circularity. **배경 빼기**: 안 함 / 세포 밖 중앙값 / 고리 object의 중앙값 (같은 세포의 고리).
  열 이름은 `Mean (GFP)`처럼 채널이 붙고, 배경을 빼면 `bg (GFP)` 열이 함께 들어갑니다.
  행 하나 = object 하나 (트랙은 시점 하나).
- **개수 · 밀도**: 부모(세포)마다 object 수, 부모 면적, 면적당 개수.
- **등거리 띠 / Coloc 2 / FRAP 회복**: 그 탭의 계산 그대로 (통합 데이터로 들어감).
- **미토 형태 (MiNA)**: 미토 조각의 골격 길이 · 가지 · 분기점 ([mitoROI](22-mito.md)).

표 이름을 비우면 `측정 · <object>`가 됩니다. 결과 표는 그래프 단계와 `1_통합데이터/`에 들어갑니다.

### 검토 (사용자 첨삭)

- **검토할 이미지**: **직접 고르기** (`4개 골랐음` 칩 + **고르기…**), **특이 사항 칩이 붙은 이미지**,
  **모든 이미지**, **멈추지 않음 (칩만 표시)**. 고른 이미지가 없으면 멈추지 않습니다.
- **고르기 창**: 열린 이미지를 그룹별 체크 목록으로, 이미지마다 특이 사항을 붙여 보여 줍니다.
  빠른 선택: 모두 · 없음 · 특이 사항 있는 것 · 그룹마다 한 장.
- **특이 사항 칩으로 표시**: 세포 수 범위 밖 · 핵 붙은 세포 · 핵 모양 이상 · 검출 실패 (켬),
  핵 없는 세포 · 가장자리 세포 (끔). **세포 수 범위** 기본 3–40개.
  **핵 모양 이상 기준**: 보통 = 구멍(채운 면적 − 면적 > 2 %) 또는 볼록 껍질에서 핵 지름의 15 % 넘게 파인 곳
  또는 볼록도 < 0.85, 엄격 < 0.90, 느슨 < 0.80. 칩은 세포질 ROI 검출이 끝날 때 계산되며 고를 때 참고용입니다
  (자동으로 대상에 넣지 않음).

실행이 검토에 오면 파이프라인 창은 숨고 메인 창 캔버스 위에 **검토 띠**가 뜹니다.

- 제목 `검토: <앞 단계>`, 칩 `파이프라인 4 / 8` · `검토 대상 1 / 4` · 이 이미지의 특이 사항.
- **대상 고르기…**, **이전** / **다음** (`⌘[` / `⌘]`), **이 이미지 확인** (`⌘↩`), **검토 끝내고 계속** (파란 버튼).
  확인하지 않은 대상이 남아 있으면 **그대로 계속** / **돌아가기**를 묻습니다.
- 왼쪽 이미지 목록의 이름 아래에 칩: `검토` (대상), `확인`, `제외`, 특이 사항 (주황 경고 / 빨강 실패 / 회색 참고).
- 고치는 방법은 [세포질 ROI 탭](03-cytosol-roi.md) 그대로 (합치기 M, 자르기 C, 지우기, 그리기, 다시 검출).
  목록 오른쪽 클릭 › **검토 대상에 넣기 / 빼기**, **이번 분석에서 제외**.
- 검토 중에는 측정 바가 숨고, 확인 · 제외는 `review_log.csv`에 남습니다.

### 그래프

**＋ 그래프 편집 창의 지금 그래프 넣기**로 [그래프 편집 창](16-graph.md)의 그래프를 단계에 넣습니다.
그래프는 열 이름으로 저장되므로 새 데이터에도 같은 모양으로 그려지고, 가리키는 표가 없으면 그 그래프만
건너뛰고 이유를 `README.txt`에 적습니다. **저장 형식** PNG · PDF · SVG, **그래프에 쓴 표 CSV**.

### 저장 · 내보내기

- **저장 위치**: **데이터 폴더의 상위 › Processed/** (기본) 또는 **직접 지정**.
- **폴더 이름 틀**: `<데이터 폴더>_<파이프라인>_<날짜>_<시각>`. 같은 이름이 있으면 ` (2)`처럼 번호를 붙입니다.
- **내보내기 종류 (이미지별)** 칩: [내보내기 창](17-export.md)의 종류 (기본 출력으로), `3_이미지/` 아래에 이미지별 폴더.
- **통합 데이터 CSV**, **프로젝트 파일**.

```
<데이터 폴더의 상위>/Processed/<데이터 폴더>_<파이프라인>_<날짜>_<시각>/
  pipeline.json      이번 실행의 모든 단계 · 설정 · 앱 버전
  project.cyproj     열면 ROI · 측정 · 파이프라인 그대로
  README.txt         단계 요약, 이미지 수, 걸린 시간, 경고, Methods 문장
  review_log.csv     검토에서 확인 · 제외한 기록
  work_log.csv       작업 기록
  summary.json       이미지 수, 이미지별 object 수, 표 행 수, 경고
  progress.jsonl     단계마다 한 줄 (진행 기록)
  1_통합데이터/       integrated_*.csv + 측정 단계의 표 (<표 이름>.csv)
  2_그래프/          <그래프>.png / .pdf / .svg + .csv
  3_이미지/          이미지별 내보내기
```

## 실행과 완료

**실행**을 누르면 문제(빠진 object, 순서, 없는 채널)를 먼저 확인하고, 데이터 폴더의 이미지를 열어
(이미 열린 것은 그대로) 단계를 차례로 돌립니다. 진행 막대에 `3 / 10 · 입자 (입자 ROI)`가 보입니다.
끝나면 **완료** 화면: 이미지 · 표 · 경고 칩, 결과 폴더, 경고 목록, 표 목록, **결과 폴더 열기**,
**그래프 편집 창에서 보기**, **측정 현황 보기**, **다른 폴더에 같은 파이프라인 실행…**, **단계로 돌아가기**.

프로젝트를 저장하면 지금 파이프라인도 함께 저장됩니다.

## 기본 프리셋 (보관함)

| 프리셋 | 단계 |
|---|---|
| 세포질 ROI · 입자 ROI · 연산 · 세기 · 개수 · 등거리 띠 | 자동 그룹 → 세포 · 핵 → 입자 → 세포 (안쪽) = 가장자리 아닌 세포 → 세포질 (입자 뺀) → 세기 · 개수 · 등거리 띠 → 검토 → 저장 |
| 입자 추적 · 세기 | 입자 추적 (탭 설정: ParticleTracker 방식, 5 신호 기준, 6 신호 변화 트랙) → 트랙 점 세기 |
| 세포질 ROI · 세기 | 세포 · 핵 → 세포 / 핵 / 세포질 세기 (배경 = 세포 밖) → 검토 (강도 측정 탭을 대신함) |
| 입자 추적 / 입자 추적 · 연산 · 세기 | 입자 추적 (→ `class = signal` 트랙만) |
| FRAP | FRAP 회복 |
| 입자 추적 · 세포질 강도 추적 · 연산 · 세기 | 세포질 강도 추적 → 분열 · 가장자리 아닌 세포 트랙 → 시점별 세기 |
| 세포질 ROI · mitoROI · 미토 형태 (MiNA) / 세포질 ROI · mitoROI · 세기 | 세포 → 미토 ROI → MiNA / 미토 조각 × 채널 세기 |
| 세포질 ROI · Coloc 2 | 세포 → Coloc 2 |
| 입자 ROI · 세기 | 입자 → 크기 · 모양 · 세기 |

프리셋 이름은 쓰는 기능을 단계 순서대로 이은 것입니다 (시작 · 검토 · 저장 단계는 빼고). 예전 이름(예: `세포질 세기`)도 `cytosol.pipe --from`에서 그대로 찾습니다.

기본 프리셋의 탭 단계는 **탭의 지금 설정**을 씁니다. 내 설정을 담아 두려면 **탭 설정 가져오기** 뒤
**저장…**으로 보관함(`~/.cytosol/pipelines/`)에 저장하세요.

## 명령줄 (cytosol-pipe)

창 없이 같은 실행기를 씁니다 (Remote Control · 무인 실행 · 다른 프로그램에서). 모든 명령은 사람이 읽는 줄을,
`--json`이면 JSON 하나를 출력합니다.

```bash
python3 -m cytosol.pipe stages [--json]          # 단계 종류 · 설정 · object 규칙
python3 -m cytosol.pipe presets                  # 보관함
python3 -m cytosol.pipe inspect <폴더>             # 이미지 · 채널 · 시점 · 픽셀 크기 · 자동 그룹
python3 -m cytosol.pipe new my.cypipe --from '세포질 ROI · 세기' --name 내분석
python3 -m cytosol.pipe edit my.cypipe --set 'stages[1].settings.bg="outside"'
python3 -m cytosol.pipe add my.cypipe op --at 2
python3 -m cytosol.pipe validate my.cypipe --folder <폴더>
python3 -m cytosol.pipe run my.cypipe <폴더> --dry-run
python3 -m cytosol.pipe run my.cypipe <폴더> [--out DIR] [--only 1,3] [--images 이름조각] [--background]
python3 -m cytosol.pipe status <결과 폴더>        # progress.jsonl / summary.json
python3 -m cytosol.pipe resume <결과 폴더>        # --review stop 으로 검토에서 멈춘 실행 이어서
python3 -m cytosol.pipe rerun <결과 폴더> --from 5
```

명령줄은 기본으로 검토에서 멈추지 않습니다 (`--review skip`). 다음 날 결과 폴더의 `project.cyproj`를 열어
고친 뒤 뒤 단계만 다시 돌리면 됩니다.
