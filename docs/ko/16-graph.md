# 그래프 편집 창

[← 설명서 목차](README.md) · [English](../en/16-graph.md)

기능 탭의 그래프를 한 창에서 열어 모양을 마음대로 고칩니다. 그래프는 모두 이 창 하나의
사이드바에 모이고, 저장은 **파일 › 내보내기…**의 **그래프** 항목에서 합니다.

## 여는 방법

- **그래프 › 현재 탭의 그래프 편집 창** (`Ctrl+G`): 오른쪽에 보이는 탭의 그래프
- **그래프 ›** (기능 이름): 결과가 있는 기능의 그래프
- **그래프 › 새 그래프 (빈 창)…**: 빈 그래프. 위쪽 데이터 칩이나 **데이터** 메뉴로 아무
  분석 결과나 CSV를 가져와 그립니다.

| 기능 | 처음 보이는 그래프 |
|---|---|
| FRAP 측정 | 탭에서 고른 그래프 그대로: 회복 곡선 + 피팅, ROI 평균 강도, 그룹 평균 ± SEM/SD (+ 개별 곡선, 피팅) |
| 라인 프로파일 | 채널마다 한 선 (채널 색, LUT에서 숨긴 채널 제외, 0–1 정규화 설정 그대로) |
| 세포질 ROI › 등거리 띠 | 세포마다 회색 선 + 빨간 평균 ± SD 띠 (탭에서 고른 x·y) |
| 세포질 ROI · 입자 ROI · 강도 측정 결과 표 | 첫 평균값 열(입자마다 측정이면 면적)의 막대 그래프 (평균 ± SD, 개별 값 점), 그룹·이미지·영역·ROI별 |
| Coloc 2 | 선택한 ROI의 2D 히스토그램을 히트맵으로 (회귀선, threshold 선). 결과 이미지를 보고 있었다면 ROI별 Pearson R 막대 |

창을 다시 열거나 **다시 불러오기** (`Ctrl+R`)를 누르면 탭의 최신 결과로 데이터를
바꿉니다. 열 이름이 그대로면 고친 설정은 그대로 둡니다. **처음 그래프로**는 모든 설정을
탭의 그래프로 되돌립니다.

## 창 구성

- **사이드바**(왼쪽): 이 창의 그래프 목록과 **새 그래프**, **복제**. 더블클릭 = 이름 바꾸기,
  우클릭 메뉴 맨 아래 빨간 **그래프 삭제…**.
- **가운데 상자**:
  - 위: **데이터** 칩. 기능(도구)마다 하나이고, 누르면 그 기능의 결과를 지금 그래프에
    가져옵니다. 아직 분석하지 않은 기능의 칩은 흐리게 보이고 누를 수 없습니다(마우스를
    올리면 무엇을 먼저 하면 되는지 나옴).
  - 가운데: 그래프 미리보기(저장할 크기와 같은 비율로 줄여 보임).
  - 아래: 데이터 표. **그래프에 쓰인 데이터**(그려진 점마다 한 행), 막대·상자 등에서는
    **그래프 요약**(n, 평균, SD, SEM, 중앙값, 최소, 최대), 그리고 기능이 넘겨준 모든 결과 표.
    셀을 골라 `Ctrl+C`(macOS `⌘C`)로 복사. 그래프와 표 사이 경계는 끌어서 바꿉니다.
- **인스펙터**(오른쪽, 폭 고정): **종류** / **값** / **모양** / **컴포넌트** 탭. **종류**, **값**,
  **모양**은 위쪽이 **선택한 요소**(그래프에서 클릭한 시리즈, 축, 제목, 범례, 글자 상자의
  설정), 아래쪽이 **전체 그래프** 설정입니다.
  - **종류**: 그래프 종류, 묶기(평균 / 중앙값), 막대·히스토그램·히트맵 설정, 선택한 시리즈의
    그리기 방식.
  - **값**: 시리즈 목록(x · y · 에러 열, 거르기, 나누기), X / Y 축(최소, 최대, 눈금 간격,
    단위, 값 배율), 선택한 요소의 글자.
  - **모양**: 크기, dpi, 배경, 배치, 글꼴, 선택한 요소의 색·굵기·점 모양·글꼴.
  - **컴포넌트**: 범례, 에러바, 글자 상자.

## 다른 분석의 데이터

위쪽 **데이터** 칩이나 **데이터** 메뉴로 지금 그래프에 데이터를 더합니다.

- **다른 분석 결과 더하기 ›** 세포질 ROI · 입자 ROI · 강도 측정 표, 등거리 띠, Coloc 2,
  라인 프로파일, FRAP, 일괄 분석 결과: 그 기능의 결과 표를 `기능 이름 · 표 이름`으로 더하고
  그 표를 쓰는 시리즈를 하나 만듭니다 (x·y 열은 데이터 시리즈 탭에서 고름).
  예: FRAP 회복 곡선 위에 라인 프로파일을, 같은 그래프에 여러 분석의 막대를.
- **CSV 파일 불러오기…**: 첫 줄이 열 이름인 CSV (쉼표, 세미콜론, 탭).
- **가져온 표 지우기…**: 그 표와 그 표를 쓰는 시리즈를 뺍니다.

가져온 표는 프로젝트에 함께 저장되고, **다시 불러오기**를 해도 남습니다.

## 그래프 위에서

**그래프 영역**, **제목**, **X·Y 축 이름**, **글자 상자**, **범례**는 모두 고르고 옮기고
크기를 바꿀 수 있는 오브젝트입니다.

- **클릭**: 고름 (파란 점선 상자). **끌기**: 옮기기.
- **오른쪽 아래 파란 핸들 끌기**: 크기. 그래프 영역은 너비·높이 (위 가장자리 고정), 글자는
  글꼴 크기 (축 이름은 X·Y가 같은 크기).
- 자동 배치인 것을 처음 끌면 지금 자리에서 직접 놓기로 바뀝니다. **그래프** 탭의 **배치**나
  오른쪽 클릭 › **모든 위치·크기 자동 배치로**로 되돌립니다.
- **두 번 클릭**: 글자 상자, 제목, 축 이름, 범례 항목 이름 고치기.
- **오른쪽 클릭**: **여기에 글자 상자 추가…**, **범례를 여기로 옮기기**, **범례 항목 추가**,
  **이 글자 상자 지우기**.

### 미리보기 확대·축소 (현미경 미리보기와 같음)

- `Cmd`(Windows `Ctrl`) + 왼쪽 버튼 위아래 드래그, `]` 확대 / `[` 축소, `Cmd`(`Ctrl`) + 휠.
- **화면 맞춤** (`Ctrl+0`), 미리보기 위의 **－ ＋** 버튼. 배율은 옆에 표시.
- 이동: 가운데 버튼 드래그, 휠 (위아래), `Shift` + 휠 (좌우). 드래그 감도는 설정의 확대
  감도를 따릅니다. 확대는 미리보기만 바꾸고 저장할 그림 크기는 그대로입니다.

## 설정

### 그래프

- **그래프 종류**: XY (선 / 점), 막대 (평균 ± 에러바), 점 그림 (개별 값 + 평균), 상자 그림,
  바이올린, 히스토그램, 히트맵 (2D).
  - XY: x 열과 y 열의 값. x가 글자면 범주 순서대로 놓습니다.
  - 막대·점 그림·상자·바이올린: x 열의 값(범주)마다 y 값을 모읍니다. x를 비우면 시리즈마다
    한 범주. 시리즈가 여럿이면 범주 안에서 나란히.
  - 히스토그램: y 값의 분포. 히트맵: 첫 시리즈의 x, y, z 열 (다른 시리즈는 위에 선으로).
- **제목**, **크기 (가로 × 세로, 인치)**, **이미지 해상도 (dpi)**, **배경색**.
- **배치**: **그래프 영역 자동 배치**와 영역의 왼쪽·아래·너비·높이 (그림 전체에 대한 비율,
  자동일 때도 지금 값이 보임), **제목 / X 축 이름 / Y 축 이름 자동 위치**, **모두 자동 배치로**.
- 막대 등: **에러바** (SD / SEM / 95 % CI / 없음), **개별 값을 점으로 표시**, 폭, 채움 투명도,
  점 흩뿌림. 히스토그램: 구간 수 (0 = 자동), 밀도, 채우기. 히트맵: 색 지도, 로그 색 눈금, 색 막대.

### 데이터 시리즈

시리즈 목록(체크 = 표시)과 **추가**, **복제**, **▲ ▼**(그리는 순서),
**값마다 나누기…**(고른 열의 값, 예: 그룹마다 색이 다른 시리즈로 나눔), 맨 끝의 빨간
**시리즈 삭제…**(확인 창에서 삭제). 범례 항목과 글자 상자도 **항목 삭제…** /
**글자 상자 삭제…**로 확인한 뒤 지웁니다.

- **데이터**: **표**, **x**, **y**, **에러 (±)** 열, **z (히트맵)**, 조건 두 개
  (**조건: 열 = 값**, **그리고 열 = 값**), **같은 스타일로 나눠 그리기**(예: 세포마다 선 하나),
  **묶기**(같은 x — 또는 **묶는 열**이 같은 행끼리 — 평균 / 중앙값, **묶을 때 에러** SD / SEM / 95 % CI).
- **이름·스타일**: **범례 이름**, **표시**, **범례에 넣기**, **모양**(선 + 점, 선, 점, 계단, 면적),
  **색**, **선 굵기**, **선 모양**(실선, 파선, 점선, 일점쇄선), **점 모양**, **점 크기**,
  **점 속 채우기**(끄면 속이 빈 점), **점 테두리**, **불투명도**, **에러 표시**(에러바 / 띠 / 없음),
  **에러바 색**(오른쪽 클릭 = 시리즈 색), **에러바 굵기**, **에러바 끝 길이**.
  **이 스타일을 모든 시리즈에**는 색을 뺀 스타일을 모든 시리즈에 적용합니다.

### 축

X 축과 Y 축마다 **이름**, **최소 – 최대**와 **자동**, **눈금 간격**과 **자동**(자동 = 보기 좋은
간격을 고름), **단위**, **값 배율**, **로그 눈금**, **보조 눈금**, **눈금 방향**, **눈금 글자 회전**.
자동일 때도 칸에는 지금 쓰는 범위와 간격이 보이고, 자동을 끄면 그 값에서 시작합니다.

- **단위**: 축 이름 뒤 괄호에 붙습니다 (`Time` + `min` → `Time (min)`; 이름 끝에 이미 괄호
  단위가 있으면 바꿈). 목록에 없는 단위는 직접 입력.
- **값 배율 (×)**: 그릴 때 값에 곱하는 수 (`1/60` 같은 분수도 됨). **단위 바꾸기…** 목록
  (s → min, min → s, s → ms, min → h, 0–1 → %, % → 0–1, µm → nm, nm → µm)은 배율과 단위를
  함께 정합니다. 배율을 바꾸면 직접 정한 최소·최대·간격도 같이 바뀌어 같은 부분을 보여 줍니다.
  데이터 표와 내보낸 CSV의 x·y도 배율을 곱한 값입니다.
**위 축선**, **오른쪽 축선**, **축선·눈금 굵기**, **격자**와 격자 색.

### 글꼴

**글꼴**(비우면 기본 글꼴, 한글은 자동으로 한글 글꼴)과 **제목**, **축 이름**, **눈금 글자**,
**범례**마다 크기, 색, **굵게**, **기울임**.

### 범례·글자

- **범례**: 표시, **위치**(자동, 그래프 위, 그래프 오른쪽, 안쪽 네 모서리, 직접 놓기), **제목**,
  **열 수**, **테두리**.
- **범례에 직접 넣는 항목**: 시리즈와 상관없는 항목을 이름, 색, 점 모양, 선 모양으로 추가.
- **글자 상자**: 글자(여러 줄), 크기, 색, 굵게, 기울임, 테두리, 정렬, 위치(축 비율: 0–1이
  축 안, 밖에도 놓을 수 있음).

## 저장

그래프 이미지(PNG / TIFF / PDF / SVG)와 데이터 CSV, 설정 JSON은 **파일 › 내보내기…**의
**그래프** 항목에서 사이드바의 그래프를 골라 저장합니다([내보내기 창](17-export.md)).
이 창의 **파일 › 내보내기…**는 그 창을 **그래프**만 켜서 엽니다. **파일 › 그래프 설정
불러오기 (전체)** / **스타일만 불러오기**로 저장한 설정(`format: cytosol-viewer-graph`)을
다른 그래프에 씁니다. CSV는 Excel에서 바로 열리는 UTF-8 (BOM)입니다.

아직 없는 기능(기준선, 피팅 곡선 직접 추가, 유의성 표시, 보조 y축)은 메뉴에 나오지 않습니다.
