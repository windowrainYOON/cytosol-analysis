# 입자 ROI 탭 (점·puncta·응축체)

[← 설명서 목차](README.md) · [English](../en/04-particle-roi.md)

메뉴 막대의 **Tool › 입자 ROI › 입자 ROI 탭 열기**로 오른쪽에 이 탭을 열고 닫습니다. 결과 저장은 **파일 › 내보내기…**([내보내기 창](17-export.md))에서 하고, 불러오기는 같은 **입자 ROI** 메뉴에 있습니다.

[세포질 ROI 탭](03-cytosol-roi.md)의 세포마다(또는 이미지 전체에서) 한 채널의
입자(밝은 점, puncta, 응축체)를 찾아 세포별로, 또는 입자 하나씩 측정합니다.
입자는 현재 Z 평면(또는 MIP)과 시점에서 찾고, ROI나 설정이 바뀌면 바로 다시
찾습니다.

## 1. 입자 ROI 추출

1. **이 이미지에서 입자 ROI 정의**를 켭니다.
2. **채널**: 입자 채널.
3. **찾을 영역**:
   - **세포질 (핵 제외)**,
   - **세포 전체**,
   - **이미지 전체 (세포 ROI 없이)**(세포 ROI가 필요 없음. 세포 ROI가 없는
     이미지에서는 미리 선택되어 있음).
4. **검출 자동화** 스위치와 **검출 방식** 선택: 검출 방식은 **자동 (유의성)**(기본, v0.65),
   **점 모양 강조 (작은 점 많을 때)**, **threshold** 가운데 하나이고, 고른 방식의 설정만 보입니다.
   - **자동 (유의성)** (v0.65): 배경(2.8 µm 가우시안)을 뺀 평활 이미지에서 잡음 σ를 아래쪽 절반
     분포로 구하고(입자는 위쪽만 늘리므로), 봉우리가 **k σ** 이상이면 입자의 씨앗으로 봅니다. 입자는
     k/2 σ 높이까지 넓히고(입자 전체를 덮음), 붙은 입자는 둘 사이가 3σ 이상 꺼질 때만 나누며,
     회절 한계 점(지름 약 0.5 µm)의 절반보다 작은 조각은 버립니다. k는 **이미지 넓이와 잡음의
     매끄러움**으로 정합니다: 잡음만으로 입자가 잡힐 기대 개수가 이미지 한 장에 **허용 노이즈
     입자**(기본 0.5)개가 되는 값(가우시안 잡음장의 Euler 특성)이라, 넓은 이미지일수록 k가 커집니다.
     쓰인 k는 그 아래 줄과 입자 정보에 늘 보입니다. 실제 TCF 형광(1464 × 1464)에서 이전 자동이
     잡음 조각을 포함해 1 900개를 잡던 것을 116개(ParticleTracker 128개)로 줄였습니다.
     - **허용 노이즈 입자**(슬라이더 + 칸): 클수록 흐린 입자까지 찾습니다(k가 작아짐).
     - **입자 기준**: 지금 쓰는 기준(기본 = 통계 / 사용자 기준: 날짜, 채널, 적용 범위)과
       **기준 잡기…** 버튼. 사용자 기준이 있으면 허용 노이즈 입자 대신 그 기준을 쓰고, ↺로 기본
       기준으로 되돌립니다. 아래 [입자 기준 잡기](#입자-기준-잡기)를 보세요.
   - **점 모양 강조 (작은 점 많을 때)**: 이전의 자동입니다. scale-normalised Hessian(둥근 점에서
     크고, 세포나 핵 경계에서는 작음)과 배경을 뺀 강도가 둘 다 세포의 중앙값 + k × MAD를 넘는
     곳을 점의 중심으로 찾고, 각 점을 자기 봉우리의 30 %까지 watershed로 넓힙니다.
     - **자동 민감도 (k)**(기본 3): 작을수록 흐린 점까지 찾습니다.
     - **입자 지름**(기본 0.4 µm, 검출 자동화가 켜져 있으면 세부 설정 안): 필터 크기를 정합니다.
       고친 값에는 **· 수정됨**과 ↺가 붙습니다. 픽셀 크기 정보가 없는 이미지는 0.1 µm/px로 봅니다.
   - **threshold**: 모든 세포에서 **수동 threshold**(슬라이더 또는 그 옆 숫자 칸)
     이상인 픽셀을 8-연결 입자로 나눕니다(ImageJ Analyze Particles와 같음).
5. **최소 입자 크기**(px): 이보다 작은 입자는 버립니다.
6. **이미지에 입자 경계 표시**: 픽셀 ROI는 자홍색, 등강도선은 주황색.

### 입자 기준 잡기

통계 기본값만으로는 "어디부터 입자인가"가 실험마다 다르므로, 경계에 있는 후보를 보고 직접 고를 수
있습니다(v0.65). 자동 (유의성)으로 처음 **이 이미지에서 입자 ROI 정의**를 켜면, 그 채널에 기준이
없을 때 "입자 기준을 먼저 잡을까요?"를 묻습니다(**기준 잡기** / **기본 기준으로 검출**). 언제든
**입자 기준 › 기준 잡기…**로 다시 잡을 수 있습니다. 탭의 설정 대신 세 단계 화면이 나옵니다.

1. **밝기**: 관대한 검출(씨앗 ≥ 2σ)로 찾은 후보 가운데 주변에 더 밝은 것이 없는 것 9개를 흐림 →
   밝음(3σ → 15σ, 로그 간격) 순서로 타일에 보여 주고, 캔버스에도 같은 번호 상자로 표시합니다.
   타일 9개는 한 표시 범위를 같이 써서 밝기 차이가 그대로 보입니다. "입자로 볼 수 있는 가장 흐린
   것"을 누르면 그 번호부터 위가 ✓로 표시됩니다.
2. **크기**: 고른 밝기 이상인 후보만으로 작음 → 큼(반치 면적) 9개를 보여 주고, 가장 작은 입자를
   고릅니다.
3. **적용**: 새 기준(밝기 ≥ 고른 후보의 SNR × 0.98, 크기 ≥ 고른 반치 면적), 이 이미지의 입자 수
   변화, 그리고 **다른 이미지의 자동 검출에도 이 기준을 쓸까요?**: **모든 이미지 (같은 채널 이름)**,
   **같은 그룹만**, **이 이미지만**. **기준 적용**을 누르면 캔버스 상자를 지우고 다시 검출합니다.

9개가 모두 입자가 아니거나 모두 입자면 **더 밝은 / 더 흐린 후보**(크기 단계는 더 큰 / 더 작은)로
다시 뽑습니다. 밝기는 배경 잡음(σ) 단위라 노출이 다른 이미지에도 같은 뜻입니다. 기준은 프로젝트에
채널 이름별로 저장되고(`particle_criterion`), 수동 threshold나 점 모양 강조로 찾는 이미지는 바꾸지
않습니다.

### 등강도선으로 형태 측정

**형태는 등강도선으로 측정 (서브픽셀)**(기본 켜짐)과 **레벨**(기본 0.5 =
반치폭): 형태 값(둘레, 원형도, solidity, AR, roundness, Feret, 타원, 중심,
등가 지름, 최근접 거리)을 픽셀 경계 대신, 배경 + 레벨 × (봉우리 − 배경)
밝기를 잇는 서브픽셀 윤곽에서 잽니다. 배경은 그 세포에서 입자 주변 3 px 안의
빈 픽셀 중앙값, 봉우리는 0.7 px 가우시안 뒤 입자의 최대값입니다. 그래서 둥근
입자가 실제로 둥글게 나옵니다(solidity ≈ 1). 끄면 ImageJ Analyze Particles와
똑같은 값입니다.

### 강도를 잴 픽셀

**강도 측정 ROI**:

- **픽셀 ROI**(기본): 입자로 잡힌 픽셀 그대로(ImageJ Analyze Particles와 같음).
- **등강도선 ROI**: 같은 레벨의 등강도선 안에 중심이 든 픽셀(ImageJ가 polygon
  ROI를 마스크로 만드는 방식). 입자 영역, 입자를 뺀 나머지, 입자마다 행,
  분배계수, [강도 측정 탭](09-intensity.md)의 논리 영역에 모두 적용됩니다.

### 여러 이미지

> v0.59부터 아래 저장 항목은 메뉴가 아니라 **파일 › 내보내기…**의 **입자 ROI** 항목에서 고릅니다([내보내기 창](17-export.md)). 저장되는 파일은 같습니다.

- **이 설정을 모든 이미지에 적용**: 같은 이름의 채널에서 같은 방법으로 모든
  이미지의 입자를 찾습니다.
- 입자 ROI 저장 / 불러오기: **입자 ROI › 입자 ROI 저장 (현재 이미지)…**로
  저장하고, **입자 ROI › 입자 ROI 불러오기…**(또는 **파일 › 불러오기**)로 다시 엽니다. `<이름>_particles.zip`, 입자마다 ImageJ ROI
  하나(`partCCC-NN`, 픽셀 경계를 따른 윤곽이라 ImageJ 마스크가 입자와 정확히
  같음. 설정은 ROI 속성에 저장). 등강도선은 옆에 `<이름>_particles_contour.zip`
  으로 저장됩니다.

## 2. 측정

### 세포별 (입자 영역 합)

세포(이미지 전체 모드는 `image`)와 영역마다 한 행, 입자 수 포함:

- **입자**: 그 세포의 입자 픽셀 전체.
- **입자를 뺀 나머지**: 찾을 영역에서 입자를 뺀 곳(`cyto - particle` 또는
  `cell - particle`, 이미지 전체는 `image - particle`).

파일: `<이름>_particle_intensity.csv`, `particle_intensity.csv`.

### 입자마다 (형태·분배계수)

입자(`partCCC-NN`)마다 한 행. 면적은 항상 들어가고, 아래 항목을 골라 넣습니다
(마우스를 올리면 정의가 보입니다).

| 항목 | 값 |
|---|---|
| 중심 X, Y | 중심 위치 |
| 둘레 | 둘레 |
| 원형도 | 4π·면적 / 둘레² (1 = 원) |
| Solidity | 면적 / 볼록 껍질 면적 (1 = 오목한 곳 없음, 낮으면 방울이 붙었거나 불규칙한 응집체) |
| 종횡비 (AR) | 맞춘 타원의 장축 / 단축 |
| Roundness | 4·면적 / (π·장축²) |
| Feret 지름 | Feret, MinFeret, Feret 각도 |
| 타원 (장·단축, 각도) | 맞춘 타원의 장축, 단축, 각도 |
| 등가 지름 | 2√(면적/π) |
| 최근접 입자 거리 | 같은 세포(또는 이미지)에서 가장 가까운 다른 입자 중심까지 거리 |
| 분배계수 | 채널마다 입자 평균 / 그 세포의 찾을 영역에서 입자를 뺀 곳(묽은 상)의 평균. 배경을 빼지 않은 원본값 |

여기에 채널마다 강도 값(Mean, IntDen, …)이 붙습니다. 등강도선 형태를 끄면
ImageJ 1.54f Analyze Particles와 값이 같습니다. 등강도선 형태를 켜면
`shape_outline`, `shape_area_um2` 열이 추가됩니다.

파일: `<이름>_particle_shape.csv`, `particle_shape.csv`.

### 이미지별·그룹별 요약

**모든 이미지 측정** 뒤 표 보기 선택에서 **요약: 이미지별**, **요약: 그룹별**을
고를 수 있습니다. 이미지 또는 그룹(세포별 모드는 영역까지)과 파라미터마다 한
행으로 `n`(입자 또는 세포 수), `mean`, `sd`(n − 1), `min`, `max`를 주고, 그룹
행에는 `n_images`가 붙습니다. 저장하면 `<suffix>_summary_image.csv`,
`<suffix>_summary_group.csv`가 생깁니다. 그룹은 이미지 목록에서 정합니다
([그룹](01-getting-started.md#그룹)).

측정 결과 표(자동 갱신, 채널별 값, 저장)는
[측정 결과 표](09-intensity.md#측정-결과-표)를 보세요.

## 팁

- 자동 (유의성)에서 흐린 입자를 놓치거나 잡음이 잡히면 **기준 잡기…**로 직접 기준을 정하거나
  **허용 노이즈 입자**를 바꾸세요. 점 모양 강조에서는 **자동 민감도 (k)**와 **입자 지름**을 씁니다.
- 이미지 사이에 똑같은 강도 기준이 필요하면 **수동 threshold**를 쓰세요.
- 응축체 형태를 보고할 때는 등강도선 형태를 켜 두고, 쓴 레벨을 함께 적으세요
  (저장소 README의 Methods 문장 참고).
